# Phase 9 支付与订阅条款草案

生效日期：2026-06-19

本文档是 HiddenShield 正式商业化前的支付与订阅条款草案，用于统一桌面端、移动端、后端和支付 provider 的产品口径。正式上线前仍需由法律顾问审阅。

## 1. 套餐分层

HiddenShield 当前商业化分层为 Free / Creator / Studio / Enterprise。

- Free：本地单文件图片 / 音频写入与验证、本地版权库；支付通道配置后可按记录购买单份版权详细报告或维权证据包。
- Creator：本地批量处理、正式云同步、订阅内正式报告、个人 L2 视频指纹存证。
- Studio：继承 Creator，并面向团队空间入口、成员权限模型、共享版权库模型和团队审计模型预留。
- Enterprise：API、私有化部署、专属云端视频处理和定制支持均以后续合同、开通验收和能力边界说明为准；不包含当前未开放为可售权益的 L3 视频画面盲水印。

本地批量处理是 Creator 订阅权益，不提供 Free 小批量试用。

## 2. Free 一次性报告商品

Free 用户可按记录购买一次性报告商品：

- 单份版权详细报告：19.9 元 / 份。
- 维权证据包：49.9 元 / 份。

一次性购买只授权对应记录 / 案件的报告，不升级订阅、不打开 Creator `report_export`，也不改变本地批量、正式云同步或 Studio 团队空间门禁。退款、撤销或风控失败后，系统只撤销对应记录 / 案件授权。

真实支付通道未配置或未通过联调时，产品应提示“支付通道尚未完成配置”，不得伪造付款成功或授权成功。

## 3. 支付 provider

首期支付 provider 为微信支付 APIv3。Stripe 等 provider 仅作为后续海外扩展预留。

客户端只展示后端返回的支付动作、订单号、状态和有效期。客户端不保存商户私钥、平台公钥、APIv3 key 或 provider secret。

## 4. 权益生效

订阅权益以云端权威 entitlement 为准。支付成功后，权益应由后端 webhook、provider 查单补偿或云端权益刷新接口写入。

用户点击“确认支付”只表示请求系统查单或刷新状态，不会绕过后端直接开通 Creator / Studio。

若支付会话过期、失败或关闭，用户需要重新创建支付会话。

## 5. 续费、取消与过期

正式上线自动续费前，产品必须在购买页、支付页或订阅管理页显著说明续费周期、扣费方式、取消方式和权益到期时间。

用户取消订阅后，已支付周期内的权益可以继续使用至周期结束。周期结束后，正式云同步、本地批量、正式报告、Studio 团队能力等付费权益应按云端 entitlement 降级。

宽限期、过期、恢复订阅和退款撤销由后端订阅状态机统一处理。

## 6. 退款与撤销

退款、撤销、争议或支付异常以支付 provider 和 HiddenShield 后端记录为准。

退款或撤销成功后，系统应撤回相应订阅权益，并将用户降级到 Free 或 expired 状态。已生成的本地版权记录仍保存在用户本机，但新的付费能力会被门禁阻断。

## 7. 云端视频计费边界

L2 视频指纹存证通常纳入 Creator / Studio 订阅权益和 usage ledger，不按 `video_minutes` 扣减。

未来 L3 端云协同画面盲水印会按订阅和视频分钟额度设计。以下仅为未来计费原则草案，不代表当前 L3 已上线、可售或可扣费：用户取消、格式不支持、服务异常、策略生成失败或自检失败不扣额度；成功完成后才入账。

## 8. 支付未上线声明

在真实微信商户沙箱 / 生产联调完成前，产品不得声明“支付已正式上线”。当前缺少微信商户配置时，应提示“支付通道尚未完成配置”。

## 9. 草案状态

本文档是 Phase 9 上线前草案，不替代正式法律审阅。正式收费上线前，需要与隐私政策、用户协议和产品内文案保持一致，并完成真实微信支付联调。
