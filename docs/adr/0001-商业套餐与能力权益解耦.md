# 商业套餐与能力权益解耦

状态：accepted

HiddenShield 不再把 Free、Creator、Studio、Enterprise 作为一条用户可见的套餐升级阶梯。当前桌面产品固定为“未付费”和“图片 / 音频年费”两种状态；图片 / 音频年费的年度授权内含本地批量和 metadata-only 云同步，正式报告按单份商品购买。团队工作区、企业集成和云视频仍以独立合同产品或能力权益建模。这样既符合已发布桌面 UI、离线许可证和云同步合同的真实范围，也避免把历史 `plan_code=creator` 同时错误解释成报告、团队、企业 API 和视频的隐式授权。旧 `plan_code` 保持兼容，后续迁移必须先以 feature entitlement 与 scope 替代任何仅靠 tier 判断的授权。
