当前可对用户承诺：

- HiddenShield 桌面端当前支持常见的 `8–48 kHz` 音频采样率和 `mono / stereo` 声道，并在保护过程中保持原始采样率与声道不变。

- 图片是否可保护由 `watermark-core` 的分块容量预检决定；`1920×1080` 仅是已通过的参考样本，不是用户可见的最小图片规格。
- 音频输入仍须满足单文件保护的最短时长和内容质量门槛；短片段、噪声底或环境底噪不属于“任意音频均可稳定验证”的承诺。

后续兼容性扩展：

- `4–8` 声道及 `48 kHz` 以上采样率属于后续兼容性扩展范围。
- 扩展必须在 `watermark-core` 内实现采样率无关的容量策略，并以原采样率、原声道保持和桌面 release 验证作为发布 Gate；不得通过重采样、降声道掩盖核心限制。

明确不能承诺：

- 低于 `8 kHz`、高于 `48 kHz` 或超过 `2` 声道的音频均能稳定写入和验证。
- 所有图片或音频格式、文件大小、分辨率、时长和声道布局均能稳定写入和验证。
- 噪声底、环境底噪类音频当前具备可发布的感知质量。
