# Pro 版本规划 (HiddenShield Pro Roadmap)

> 历史归档：本文为早期 Pro 设想，已废弃；当前封版口径以 `docs/当前真实能力边界说明.md` 和 `docs/封版收口计划.md` 为准。L3 视频画面盲水印仅限内部测试，不进入本版 UI、权益、云任务、账本或销售话术。本版 Studio 仅预留团队空间、成员权限模型、共享版权库模型和团队审计模型，不开放真实成员管理或共享操作。

## 定位

免费版解决"能用"，Pro 版解决"好用 + 法律效力 + 规模化"。

## Pro 功能矩阵

### 1. 多平台并行输出

- 免费版：每次仅支持 1 个平台
- Pro 版：2-N 个平台并行压制，GPU 串行队列保证稳定性

### 2. PDF 取证报告导出

- 排版精美的 PDF 版权存证报告
- 带隐盾官方认证章 UI
- 包含 TSA 签名验证结果（ASN.1 解析）
- 可直接提交给平台法务/法院

### 3. 区块链/国家授时中心存证

- 机制：本地加完水印后，仅上传 SHA-256 哈希 + 水印 UID（不上传原文件）
- 云端对接国家授时中心（中科院）申请可信时间戳
- 批量打包当天哈希树（Merkle Tree）上链（蚂蚁链/腾讯至信链）
- 法律闭环：提供的不再是本地报告，而是"国家授时中心认证的固化电子证据"

### 4. 视频画面水印（双通道冗余，历史设想，已废弃）

- 历史设想，已废弃；本版仅可承诺 L1 视频音轨水印和 L2 视频指纹存证。
- L3 视频画面盲水印仍只限内部测试，不作为 Pro / Studio / Enterprise 可售能力。

### 5. 批量处理

- 文件夹拖入，批量嵌入水印
- 批量压制多平台输出
- 进度队列管理

### 6. 云端版权金库同步

- 本地金库加密同步到云端
- 跨设备版权记录统一管理
- 团队协作：历史设想，已废弃；本版 Studio 仅预留团队模型和入口。

| 项目 | 优先级 | 备注 |
