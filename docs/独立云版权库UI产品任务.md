## 2. 产品目标

为图片 / 音频年费已激活、且服务端返回 `cloud_sync=true` 的账户建立个人库优先的独立云版权库 UI，使用户能够在不上传原始媒体、保护副本或本地文件路径的默认隐私边界下，查看同一账户的云端版权记录及其同步状态。

第一版只解决“看得见、看得懂、能定位异常”：

- 查看个人云版权记录列表和详情。
- 查看同步时间、设备来源和同步状态。
- 查看冲突、registry 登记、公开元数据和报告状态。
- 在错误、离线、权益不足和数据为空时给出真实、可恢复的状态。

## 3. 非目标

- 不在第一版实现团队工作区共享库。
- 不实现跨成员转让、归档或撤销。
- 不实现企业集成写 API；未来集成保持只读。
- 不开放支付、套餐购买、团队管理、云视频或生产 SLA。
- 不默认上传原始媒体、加水印媒体、保护副本或本地绝对路径。
- 不修改 `watermark-core` 的 payload、版权编号、写入、读取、验证或 rewrite 规则。
- 不以本任务解冻移动端发布；移动端继续遵守现有冻结和跨端 Gate。

## 4. 统一信息架构

个人库列表至少展示：

- 版权编号。
- 媒体类型与用户可识别的作品名称。
- 最近同步时间。
- 同步状态。
- registry 登记状态。
- 公开元数据状态。
- 报告状态。

记录详情至少展示：

- 创作者声明和记录来源设备。
- 创建、更新与最近同步时间。
- 内容摘要和允许展示的媒体元数据。
- 父级编号、版本关系和写入次数。
- 同步 cursor 对应的用户可读状态，不直接暴露内部 cursor 值。
- 冲突原因、受影响字段和建议操作。
- registry、公开元数据、报告状态及其边界说明。
- “不构成法律授权或侵权结论”的固定说明。

统一状态词必须由共享映射产生，桌面、Android、iOS 和未来 Web 不得自行创造不同语义：

- 同步：`已同步`、`同步中`、`已暂停`、`待重试`、`冲突待处理`、`权益未开放`。
- Registry：`待登记`、`已预留`、`已生效`、`登记失败`。
- 公开元数据：`未生成`、`可导出`、`需刷新`。
- 报告：`未生成`、`草稿`、`可购买`、`已购买`、`可导出`。

## 5. Tracer Slices

### Slice 1：图片 / 音频年费个人库只读闭环

阻塞：商业套餐与权益 P1 DTO / contract 对齐。

交付：

- 使用正式 auth / cloud sync / registry HTTP 主链读取当前账户的个人版权记录。
- 独立入口展示加载、空列表、成功列表、未登录、权益不足、离线和服务错误状态。
- 列表进入详情后可查看同步、registry、公开元数据和报告状态。
- 不读取或上传原始媒体、保护副本和本地路径。

验收：

- [ ] 同一图片 / 音频年费有效账户在至少两个设备来源写入的记录能出现在同一列表。
- [ ] 未付费、图片 / 音频年费、未登录、离线和后端错误路径均有真实状态，不使用 mock 成功数据。
- [ ] UI 字段与现有 sync / registry contract 一致，不新增第二套版权记录模型。
- [ ] 桌面页面级 QA 通过；移动适配层复用同一状态映射。

### Slice 2：同步诊断与冲突可视化

阻塞：Slice 1。

交付：

- 展示最近同步、来源设备、暂停 / 恢复、待重试和 cursor 连续性结果。
- 展示冲突类型、受影响字段和下一步建议。
- 第一版只提供安全的重试 / 刷新动作，不提供未经合同定义的服务端覆盖或强制合并。

验收：

- [ ] 暂停、恢复、失败重试和双向记录往返均能映射到一致状态。
- [ ] 冲突不会静默覆盖本地或云端记录。
- [ ] 桌面 / 移动使用同一冲突词汇和恢复建议。

### Slice 3：Registry、公开元数据与报告状态

阻塞：Slice 1。

交付：

- 在详情页组合展示 registry 状态、公开元数据状态和报告状态。
- 清晰区分技术状态、用户操作和法律边界。
- 复用既有公开权利 / 报告合同，不在 UI 中推导新的法律结论。

验收：

- [ ] reserve、confirm、失败与待登记状态可被正确展示。
- [ ] `legalConclusion=false` 及“不构成法律结论”文案保持一致。
- [ ] 未购买报告、已购买报告和可导出状态不互相混淆。

### Slice 4：跨端页面级 QA 与发布 Gate

阻塞：Slice 1、Slice 2、Slice 3。

交付：

- 建立桌面、Android、iOS 的同账号记录与状态对照矩阵。
- 验证桌面写入 / 移动读取、移动写入 / 桌面读取所形成的记录展示一致。
- 验证慢网、断网、token 过期、权益变化、重复事件和 cursor 重放。

验收：

- [ ] 桌面安装候选页面级 QA 通过。
- [ ] Android 页面级 QA 通过；移动端冻结解除前只作为内部证据。
- [ ] iOS 在可用 macOS / Xcode / 真机或模拟器环境中通过；缺少环境时必须保留明确外部阻塞。
- [ ] 新增独立 `cloud:vault-ui-release-gate`，聚合 contract、E2E、隐私边界和页面级证据。

## 6. 隐私与安全 Gate

- 所有请求必须使用正式账户会话和既有 workspace / device 边界。
- 日志、错误信息和 telemetry 不得包含 token、原始媒体字节、保护副本字节或本地绝对路径。
- QA entitlement grant 不得进入生产 UI 或公开管理入口。
- 删除、覆盖、合并和跨成员操作在第一版全部 fail closed。
- UI 不得因为后端字段缺失而把未知状态显示为成功。

## 7. 完成定义

只有以下条件全部满足，才能把“独立云版权库 UI 第一版”标记为完成：

- 年度授权个人库列表与详情使用正式服务和真实账户数据。
- 同步、冲突、registry、公开元数据和报告状态均有完整正常 / 空 / 错误路径。
- 默认隐私边界通过自动合同和页面级验证。
- 桌面发布 Gate 通过；移动端按冻结状态保留内部证据或完成独立发布 Gate。
- `docs/商业化落地Roadmap.md`、`docs/双端能力一致性Roadmap.md` 和 `docs/当前真实能力边界说明.md` 已按最终真实状态更新。
