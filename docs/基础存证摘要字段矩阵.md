# HiddenShield 基础存证摘要字段矩阵

状态：`V1 已冻结`

冻结日期：2026-07-17

适用范围：当前桌面端图片 / 音频版权记录、批量处理结果和版权库复制摘要。移动端当前冻结；未来恢复移动端时必须复用同一字段语义。

## 1. 产品层级

HiddenShield 对外材料固定分为三层：

| 层级 | 商品边界 | 当前价格 / 权益 | 用途 |
| --- | --- | --- | --- |
| 基础存证摘要 | 免费 | 未付费与图片 / 音频年度基础权益均可查看、复制 | 日常留档、作品管理、基础验证信息分享 |
| 版权证据技术报告 | 记录级付费 | `copyright_report_single`，当前 `¥19.9 / 份` | 平台申诉、律师咨询和结构化技术事实整理 |
| 维权证据包 | 记录 / 案件级付费 | `rights_evidence_pack_single`，当前 `¥49.9 / 份` | 组织争议对象、截图、链接、附件和证据清单 |

冻结约束：

- 图片 / 音频年度注册码不直接授权版权证据技术报告或维权证据包。
- 基础存证摘要不是正式报告，不包含购买状态、价格、套餐名称或营销文案。
- 版权证据技术报告和维权证据包不得输出法律权属结论、侵权结论、司法鉴定结论或法院采信承诺。
- 当前视频能力冻结；基础摘要不得输出视频水印、视频指纹或视频画面任务字段。

## 2. 展示等级

| 等级 | 含义 |
| --- | --- |
| `D 默认展示` | 只要记录存在就展示；缺失值使用冻结的边界文案，不使用模糊的“未记录”代替业务状态 |
| `C 条件展示` | 只有满足明确条件时展示；条件不满足时整行省略 |
| `R 付费报告` | 不进入基础摘要，只进入已购买的版权证据技术报告或维权证据包 |
| `X 禁止展示` | 不得进入基础摘要、正式报告、同步摘要或对外复制内容 |

数据库支持标记：

| 标记 | 含义 |
| --- | --- |
| `现有` | 当前 `VaultRecord` 已具备字段，可直接投影 |
| `派生` | 可由现有字段或固定产品规则安全派生，不需要数据库迁移 |
| `API` | 数据库已有或运行态可得，但桌面 `VaultRecord` / IPC 尚未正式暴露 |
| `DB` | 需要新增持久化字段或记录关联 |
| `报告` | 由报告导出、Manifest、签名或购买授权模型提供，不属于版权记录本体 |

## 3. 基础摘要字段矩阵

### 3.1 摘要身份与边界

| 规范字段 | 用户标签 / 固定文案 | 等级 | 数据支持 | 规则 |
| --- | --- | --- | --- | --- |
| `summary_schema_version` | 摘要格式版本：`HS-SUMMARY-1` | `R 付费报告` | `派生` | 基础摘要复制文本不强制展示；机器报告必须记录 |
| `summary_title` | `【HiddenShield 本地版权记录摘要】` | `D 默认展示` | `派生` | 不再使用未限定的“隐盾版权存证”作为标题 |
| `record_nature` | `记录性质：HiddenShield 本地版权记录，非第三方公证、官方登记或法律权属结论` | `D 默认展示` | `派生` | 固定边界文案 |
| `watermark_uid` | 版权编号 | `D 默认展示` | `现有` | 展示完整 `HS-...` 编号 |
| `revision` | 版本次数 | `D 默认展示` | `现有` | 使用“第 N 次” |
| `parent_watermark_uid` | 上一版编号 | `C 条件展示` | `现有` | `revision > 1` 且字段存在时展示 |
| `rewrite_reason` | 更新说明 | `C 条件展示` | `现有` | 非空时展示 |

### 3.2 创作者信息

| 规范字段 | 用户标签 / 固定文案 | 等级 | 数据支持 | 规则 |
| --- | --- | --- | --- | --- |
| `creator_display_name` | 创作者显示名称 | `D 默认展示` | `现有` | 不使用“创作者身份”暗示实名认证 |
| `creator_identity_source` | 身份信息来源：用户本地声明 | `D 默认展示` | `派生` | 当前固定为用户声明 |
| `creator_identity_verification_status` | 身份核验状态：未进行实名认证 | `D 默认展示` | `派生` / `DB` | 当前由产品边界派生；未来接入真实核验后需要结构化字段 |
| `creator_account_id` | 账户 / 工作区主体标识 | `R 付费报告` | `DB` | 只输出稳定脱敏标识，不输出手机号、邮箱或登录 token |

### 3.3 写入与回读验证

| 规范字段 | 用户标签 / 固定文案 | 等级 | 数据支持 | 规则 |
| --- | --- | --- | --- | --- |
| `write_verification_status` | 保护副本验证 | `D 默认展示` | `现有` | 使用“已通过 / 未通过 / 未完成” |
| `write_verification_message` | 验证说明 | `C 条件展示` | `现有` | 成功文案固定为“已从保护副本回读并验证版权编号，可由 HiddenShield 再次读取验证”；禁止使用“可取证” |
| `write_verification_at` | 验证完成时间 | `C 条件展示` | `现有` | 有值时展示；与处理时间相同仍可保留，但不得重复写入次数 |
| `verification_target_digest` | 验证对象摘要（SHA-256） | `R 付费报告` | `DB` | 明确验证针对哪一个保护副本字节对象 |
| `verification_method` | 验证方法 / 读取路径 | `R 付费报告` | `报告` | 记录图片 / 音频读取方法、核心版本和结果 |
| `verification_log` | 完整验证步骤与错误码 | `R 付费报告` | `报告` | 不进入基础摘要 |

### 3.4 版权编号与联网登记

| 规范字段 | 用户标签 / 固定文案 | 等级 | 数据支持 | 规则 |
| --- | --- | --- | --- | --- |
| `watermark_issue_mode` | 版权编号生成方式 | `D 默认展示` | `现有` | 使用“本地离线生成 / 后端预留 / 后端已确认”等产品文案，不使用“签发模式”暗示官方签发 |
| `registry_status` | 联网登记状态 | `D 默认展示` | `现有` | 明确“等待登记 / 已预留 / 已登记 / 登记冲突” |
| `registry_receipt` | 登记收据编号 | `C 条件展示` | `现有` | 仅在已登记且收据存在时展示；等待登记时整行省略，不显示“未记录” |
| `registry_provider` | 登记服务 | `C 条件展示` | `DB` | 已登记时展示服务方 |
| `registry_confirmed_at` | 登记确认时间 | `C 条件展示` | `DB` | 已登记时展示 |
| `registry_receipt_digest` | 登记收据摘要（SHA-256） | `R 付费报告` | `DB` | 报告中展示摘要，不默认展示原始收据正文 |
| `registry_raw_receipt` | 原始登记收据 | `R 付费报告` | `报告` | 作为 JSON / 附件引用，不直接堆入摘要正文 |

## 5. 永久禁止进入对外材料的字段

| 字段 / 信息 | 禁止原因 |
| --- | --- |
| `protected_copy_path`、原文件完整本地路径 | 暴露用户目录、用户名和设备结构 |
| `tsa_token_path` | 仅为本地附件定位，不是对外证据字段 |
| installation secret、installation ID、离线许可证原始 token | 设备绑定与授权安全信息 |
| 登录 token、手机号、邮箱、支付密钥、Provider secret | 账户与支付安全信息 |
| SQLite 自增 `vault_record.id` | 本地实现标识，不是稳定对外编号 |
| 原始诊断日志中的绝对路径、堆栈和系统环境秘密 | 隐私与安全风险 |
| 套餐名称、价格、购买按钮文案 | 基础摘要是证据事实投影，不是营销材料 |
| “已确权”“司法有效”“法院认可”“构成侵权”等结论 | 当前能力边界禁止承诺 |
| 当前冻结的视频任务、视频指纹和视频画面字段 | 不属于图片 / 音频发布基线 |

## 6. V1 基础摘要固定结构

```text
【HiddenShield 本地版权记录摘要】

【记录信息】
记录性质
版权编号
版本次数
创作者显示名称
身份信息来源
身份核验状态

【写入与验证】
保护副本验证
验证说明（条件）
处理完成时间
验证完成时间（条件）

【编号与登记】
版权编号生成方式
联网登记状态
登记收据编号（条件）

【文件证据】
媒体类型
原文件名
作品指纹（SHA-256）
保护副本名称
保护副本摘要（SHA-256）
图片尺寸 / 音频时长（条件）
输出策略

【时间信息】
时间依据
网络授时时间（条件）
第三方时间证明
可信时间与时间证明服务（仅已验证 TSA）

【创作者声明】
固定声明边界
作品来源声明
训练许可声明
创作方式声明
人工编辑声明
真实性声明
自定义版权声明（条件）

【技术验证信息】
水印协议版本
载荷完整性校验

---
本摘要在本地生成；原始媒体和保护副本未上传。版权元数据是否同步，以当前同步设置和联网登记状态为准。
```

格式规则：

- 可选字段必须在拼接前过滤，不允许产生连续空行。
- 中文标签统一使用全角冒号或统一模板标点，不混用中英文格式。
- 时间统一使用 `YYYY-MM-DD HH:mm:ss`，不使用操作系统区域化的 `17/7/2026 上午...` 格式。
