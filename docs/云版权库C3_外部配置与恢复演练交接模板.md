# 云版权库 C3 PostgreSQL Role / Secret Reference 与恢复演练交接模板

状态：`external_configuration_pending`

本模板交付给基础设施与安全团队。只允许填写 Secret reference、provider metadata 和已签署的证据链接；不得写入密码、private key、raw JWT、JWKS 私密材料或真实 connection string。

## 1. Internal Identity Provider

| 项 | 必填值 | 验收 |
| --- | --- | --- |
| provider kind | `JWKS` 或 `mTLS` | 与 C3 receipt adapter allowlist 匹配。 |
| provider ID | `<immutable-provider-id>` | 不使用 example/placeholder。 |
| audience | `hiddenshield-cloud-copyright-internal` | 与 receipt fixture 一致。 |
| Secret reference | `<secret-manager-reference>` | 仅引用，不含 secret value。 |
| JWKS / mTLS metadata reference | `<immutable-metadata-reference>` | 版本化、可审计。 |
| workload identity reference | `<workload-identity-reference>` | 仅受控 internal service 可读。 |
| unavailable behavior evidence | `<runbook-or-test-reference>` | adapter 在 transaction 前 fail-closed。 |

## 2. PostgreSQL Role Bootstrap

| Role | 预期属性 | Secret reference |
| --- | --- | --- |
| `hiddenshield_cloud_copyright_owner` | `NOLOGIN`，仅 migration owner | `N/A` |
| `hiddenshield_cloud_copyright_app` | `LOGIN NOSUPERUSER NOBYPASSRLS NOINHERIT` | `<secret-manager-reference>` |
| `hiddenshield_cloud_copyright_internal_service` | `LOGIN NOSUPERUSER NOBYPASSRLS NOINHERIT` | `<secret-manager-reference>` |

验收必须证明：

- runtime role 不是云版权库 table owner，且没有 `BYPASSRLS`；
- RLS 已 `ENABLE` 与 `FORCE`；
- runtime role 没有 DDL、`SET ROLE`、`PUBLIC` grant 或跨 workspace 默认权限；
- role/bootstrap 命令来自受控 IaC reference，且至少两位审批人已签署。

## 3. 恢复演练证据

| 演练 | 必须证据 | 通过条件 |
| --- | --- | --- |
| identity provider unavailable | provider health 失败 receipt、adapter log digest | 零 transaction/零业务写入。 |
| stale JWKS / mTLS failure | 验真拒绝 evidence | 固定 fail-closed reason，无 scope 注入。 |
| app role rotation | 新旧 Secret reference、连接池 drain evidence | 旧 role 凭据不可新建 scope transaction。 |
| backup restore to staging | backup ID、restore timestamp、schema checksum | `0023`/`0024` 与 C0-C3 contracts 通过。 |
| RLS scope isolation | 双连接 QA artifact | 无 workspace 泄露、无 scope bleed。 |
| rollback | migration down/staging restore evidence | 无未审计的权限残留。 |

## 4. 交接完成声明

```text
provider metadata: <reference>
role bootstrap IaC: <reference>
secret references verified: <yes/no>
two-person approval references: <reference>
staging drill artifact: <reference>
open exceptions: <none or tracked issue>
```

任一项缺失时，C3 adapter、`0024` migration、internal API 与 production role 发放继续关闭。

## 5. 本地交接预检

在未提供真实配置时：

```text
npm run cloud:copyright-c3-external-readiness
```

必须返回 `blocked`，且没有 provider/database/API 副作用。基础设施团队填写引用后，dry-run 只可返回 `ready_for_review`；这仍不是部署授权，下一步只能评审 `0024` SQL 与 adapter fixture。

```text
npm run cloud:copyright-c3-secret-scan
```

该 Gate 拒绝 C3 合同与交接材料中的 PEM private key、JWT、含密码的 PostgreSQL URL 和字面 secret assignment。
它也拒绝传入 `<secret-manager-reference>`、`example`、`placeholder`、`TODO` 或 `TBD` 等未替换引用。
