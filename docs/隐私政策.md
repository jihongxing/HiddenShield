# HiddenShield 隐私政策

生效日期：2026-06-19

本政策用于说明 HiddenShield（隐盾）在桌面端、移动端和云端能力中如何处理您的本地数据、云同步数据、联网取证请求与匿名统计信息。

## 1. 默认处理原则

隐盾默认采用本地优先原则。您导入的图片、音频、视频素材及生成产物，默认仅在您的设备内完成探测、水印写入、验证和摘要生成。

除非您明确发起特定云端能力，隐盾默认不同步、不同传原始图片、加水印图片、原始音频、加水印音频、原始视频、加水印视频、本地文件路径和本地指纹包路径。

在未获得您的确认前，隐盾不会主动向外部服务发起联网取证请求，也不会发送匿名统计事件。

## 2. 我们可能处理的数据类别

本地数据包括但不限于：创作者身份、版权库记录、水印编号、写入次数、父级编号、验证状态、文件摘要、媒体类型、时间戳回执、本地批量任务、失败原因、应用设置、日志、缓存和崩溃诊断信息。

云同步首期只同步账户、工作区、设备、创作者档案、订阅权益、版权记录元数据、取证记录、审计记录和同步状态摘要，不包含原始媒体、加水印媒体和本地路径。

若您开启联网取证，应用会在相关服务配置并可用时向第三方时间戳服务和公开站点发送最小必要的请求参数，用于换取 RFC 3161 回执或 HTTP Date 时间信息，不会上传原始素材文件本身；未配置或不可用时，不承诺生产可信时间戳链路。

## 3. L2 视频指纹存证

L2 视频能力是“画面指纹存证 / 相似性取证增强”，不是视频画面盲水印。

L2 流程中，客户端优先在本地生成不可逆视频画面指纹包，云端只接收摘要、采样策略、指纹根、bundle 摘要、存证收据和必要的审计元数据。

L2 不上传原始视频、加水印视频、本地视频路径或本地 bundle 路径。若请求中包含原始视频或本地路径，后端必须拒绝。

## 4. 匿名统计与崩溃信息

若您选择开启匿名统计，隐盾可能记录匿名 install id、匿名 session id、应用版本、功能名、成功/失败、错误码、耗时、文件类型桶、文件大小桶与脱敏后的崩溃堆栈摘要，以帮助定位产品稳定性问题。

匿名统计设计目标是不包含原始媒体、加水印媒体、文件名、本地路径、完整媒体 hash 或可直接还原作品内容的数据。您可随时在“设置”中关闭该能力。

## 5. 支付与订阅数据

在支付通道配置并通过联调后开通 Creator 或 Studio 时，客户端只向后端请求 payment session。客户端不得保存微信支付商户密钥、APIv3 key、商户私钥、平台公钥或 provider secret。

正式权益只能由后端 webhook、provider 查单补偿或云端权威权益接口写入。客户端点击“确认支付”只触发查单或刷新，不直接开通权益。

真实支付通道未配置或未通过联调时，产品应提示“支付通道尚未完成配置”，不得把 fixture / 测试验收路径写成真实扣款。

## 6. 第三方网络服务

当您开启相关能力后，隐盾可能访问 HiddenShield 云服务、配置后的微信支付、配置后的 RFC 3161 时间戳服务与公开网络授时站点。这些第三方服务独立运营，可能基于其自身规则记录访问日志、请求时间、支付记录和来源网络信息。

我们建议您在企业或敏感项目环境中，由运维提前评估并白名单化相关域名、出口策略与审计要求。

## 7. 用户控制权

您可随时在“设置”中关闭联网取证、关闭匿名统计、导出崩溃日志，或通过“清除所有数据”删除本地版权库、身份信息、日志、回执与缓存。

关闭联网取证后，隐盾仍可继续执行本地版权处理，但不再尝试获取第三方时间戳回执或网络授时信息。

## 8. 数据安全与保留

隐盾不提供云端托管或远程恢复功能，相关本地数据的可用性取决于您的设备安全、磁盘状态与备份策略。

如未来产品处理方式发生重大变化，我们会在新版本中更新本政策，并在必要时重新征求您的确认。
