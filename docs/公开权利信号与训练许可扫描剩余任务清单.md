# 公开权利信号与训练许可扫描剩余任务清单

更新时间：2026-07-02

本文是 `docs/公开权利信号与训练许可扫描协议设计.md` 的收口清单，只记录当前还没有完全收完的 5 个事项。推进顺序固定为：

1. 生产证书链
2. iOS QA
3. 外部 SDK 发布
4. release 样本池
5. 客户签字

任何后续任务如果想插队，都必须先把前一项状态说明清楚。

## 1. 剩余任务总表

| 顺序 | 任务 | 当前状态 | 依赖 | 完成标准 | 下一步 |
| --- | --- | --- | --- | --- | --- |
| 1 | 生产 C2PA 证书链 / TSA 配置 | 阻塞，已接 completion gate | 外部 CA / TSA、secret manager、发布负责人签字 | 生产环境真实注入 `HIDDENSHIELD_C2PA_SIGN_CERT_PEM`、`HIDDENSHIELD_C2PA_PRIVATE_KEY_PEM`、`HIDDENSHIELD_C2PA_SIGNING_ALG`、`HIDDENSHIELD_C2PA_TSA_URL`，并通过 `rights:metadata-embed-production-staging-qa`；再把 JSON 证据传给 `HIDDENSHIELD_PUBLIC_RIGHTS_C2PA_TSA_VALIDATION_JSON` | 先完成证书申请、私钥托管和 secret 注入，再跑 staging QA 与 `public-rights:completion-gate` |
| 2 | iOS 运行态 QA | 阻塞，已补专属入口 | macOS + Xcode + iOS Simulator 或真机 | iOS 端通过 `rights:ios-public-rights-v3-runtime-qa`，覆盖公开元数据 JSON、图片嵌入副本、V3 默认写读，并把 JSON 证据传给 `HIDDENSHIELD_PUBLIC_RIGHTS_IOS_QA_JSON` | 恢复 iOS 环境后补同场景 QA，不能用 Android 替代 |
| 3 | 外部 SDK 发布 | 阻塞，已接 completion gate | 生产信任链、发布负责人、npm 发布权限 | `packages/public-rights-sdk` 完成对外 npm 发布，README、版本号、包内容和边界说明全部通过，并提供 `public_rights_sdk_npm_publish_v1` JSON | 先把生产 C2PA / TSA 收口，再做外发包发布验收 |
| 4 | release 样本池 | 阻塞，已接 completion gate | 样本池、真实素材、性能基线、门禁脚本 | 补齐更完整的图片 / 音频 / L1 视频音轨 release 样本池，输出 `public_rights_release_sample_pool_v1` JSON：图片至少 24、音频至少 12、L1 视频音轨至少 6 且记录 p95 耗时 | 先扩充真实样本池，再补性能基准和 full gate |
| 5 | 客户签字 | 阻塞，已接 completion gate | 前四项完成、客户 SLA、支持联系人、回滚窗口 | 首批 Enterprise / 试点客户完成 SLA、联系人、升级路径和签字确认，并提供 `enterprise_customer_signoff_v1` JSON | 前四项完成后再做客户交付和签字 |

## 2. 当前已完成的前置项

这些事情已经不是剩余任务，但它们是上面 5 项的前提：

- 公开查询 API 和公开元数据 sidecar 已落地。
- 图片 / 音频 / L1 视频音轨的公开元数据传播层和 C2PA 运行态 QA 已落地。
- `packages/public-rights-sdk` 已有仓库内分发包和合同门禁。
- `rights_manifests`、公开权利查询、Enterprise 只读批量路由和内部 dry-run 网关已经实现。
- V3 最小锚点和默认 V3/39 已切到 `watermark-core`。

这些前置项不等于生产收口完成，只是说明主路径已经铺好。

## 3. 推进规则

- 不允许跳过顺序。
- 不允许把 iOS QA、SDK 发布或客户签字包装成“已经完成”。
- 不允许把 staging signer 当成 production trust chain。
- 不允许把 Android 结果当成 iOS 替代证据。
- 不允许把 release smoke 当成完整真实素材池。
- 不允许跳过 `public-rights:completion-gate`。默认运行会输出 BLOCKED 报告；设置 `HIDDENSHIELD_PUBLIC_RIGHTS_REQUIRE_COMPLETE=1` 后，必须同时提供生产 C2PA/TSA、iOS QA、npm 发布、release 样本池、客户签字 5 份真实 JSON 证据才允许通过。

## 3.1 Completion gate

新增机器门禁：

- `rights:ios-public-rights-v3-runtime-qa`：在 iOS Simulator 或真机上运行 `mobile_app/tool/ios_public_rights_v3_runtime_qa.dart`，覆盖公开权利 JSON、公开元数据 JSON、PNG 图片嵌入副本字节检查、默认 V3/39 写读。
- `public-rights:completion-gate`：收口 5 个外部阻断项。默认输出 BLOCKED 证据但不伪造完成；强制模式需要设置 `HIDDENSHIELD_PUBLIC_RIGHTS_REQUIRE_COMPLETE=1` 并提供以下环境变量：
  - `HIDDENSHIELD_PUBLIC_RIGHTS_C2PA_TSA_VALIDATION_JSON`
  - `HIDDENSHIELD_PUBLIC_RIGHTS_IOS_QA_JSON`
  - `HIDDENSHIELD_PUBLIC_RIGHTS_SDK_NPM_PUBLISH_JSON`
  - `HIDDENSHIELD_PUBLIC_RIGHTS_RELEASE_SAMPLE_POOL_JSON`
  - `HIDDENSHIELD_PUBLIC_RIGHTS_CUSTOMER_SIGNOFF_JSON`

## 4. 结论

这 5 项就是当前公开权利协议的最终收口面。当前代码侧已经把 5 项接入 `public-rights:completion-gate`；在真实外部 artifact 提供并通过强制模式前，状态仍是阻塞，不能写成生产发布完成。

如果它们都完成了，`docs/公开权利信号与训练许可扫描协议设计.md` 才能往“生产发布完成”继续收口。
