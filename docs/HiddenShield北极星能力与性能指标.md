# HiddenShield 北极星能力与性能指标

更新时间：2026-06-30

本文档定义 HiddenShield 应长期具备的产品能力、技术能力、商业能力和性能指标。它是“北极星目标”，不是当前真实能力承诺。任何对外文案、订阅权益、销售材料、帮助中心、正式报告或合同条款，仍必须以 `docs/当前真实能力边界说明.md` 为准。

4.0 支持格式总表中的“正式支持”指北极星目标支持，不代表当前已完成的产品承诺。

本文档后续用于：

- 统一团队对 HiddenShield 最终形态的判断。
- 把功能讨论转化为可验收能力。
- 把“能不能做”转化为质量、性能、隐私、安全和商业边界指标。
- 为 Roadmap、版本计划、QA 门禁、商业化包装和客户交付提供上层目标。

## 1. 产品北极星

HiddenShield 的北极星是：

让创作者和团队在不默认上传原始媒体的前提下，为图片、音频和视频建立可跨端验证、可登记、可同步、可报告、可公开传播、可商业化管理的版权保护与权利声明基础设施。

这句话拆成六个产品结果：

1. 本地优先：用户不登录、不联网也能完成基础保护副本写入、验证和本地版权库保存。
2. 可信编号：每个正式保护副本都有记录级版权编号，能在线登记，离线兜底，联网补登记。
3. 跨端一致：桌面端、Android、iOS 和未来云任务对同一类正式能力使用同一套核心算法和同一套字段语义。
4. 云端元数据：Creator 及以上用户自动同步版权库元数据，Free 用户只保存本地版权库。
5. 公开传播：公开权利、训练许可和作品声明通过 registry 与 C2PA / CAWG / IPTC / XMP / JSON-LD 传播层表达，不扩大媒体内 payload。
6. 商业闭环：Free、Creator、Studio、Enterprise 分层清晰，报告、批量、云同步、团队空间、公开扫描和未来云视频各有明确门禁、计费和风控边界。

## 2. 非目标与硬边界

这些内容不是北极星的一部分，除非先更新真实能力边界、Roadmap 和对应发布门禁：

- 不把 C2PA、训练许可或公开权利查询包装成法律授权结论。
- 不把 L2 视频指纹存证包装成视频画面盲水印。
- 不把 L1 视频音轨水印包装成视频画面水印。
- 不把 L3 staged 测试包装成 Studio / Enterprise 可售能力。
- 不默认上传原始媒体、保护副本字节、本地路径或可还原媒体内容。
- 不在 `watermark-core` 之外实现正式盲水印算法。
- 不为 Web preview、mock ID、preview marker 建立正式版权库、报告或云同步路径。
- 不开放额外外部 API，除非先完成 API 契约、鉴权、限流、审计、额度和隐私边界设计。
- 不把生产前的 staging C2PA / TSA 当成公开信任链。

## 3. 能力分层

### 3.1 Free

Free 是本地可信入口。

北极星能力：

- 单文件图片写入、验证和本地版权库保存。
- 单文件音频写入、验证和本地版权库保存。
- L1 视频音轨水印本地写入和验证。
- 本地版权库查看、搜索、筛选、详情和复制摘要。
- 本地保护副本导出或系统分享。
- 本地正式报告预览。
- 按单条记录购买正式报告或维权证据包。

明确限制：

- 不开放正式云同步。
- 不创建本地批量队列。
- 不默认获得 Creator 正式报告权益。
- 不获得 L2 视频指纹云存证提交权益。
- 不获得团队共享版权库。

### 3.2 Creator

Creator 是个人创作者生产力层。

北极星能力：

- 包含 Free 全部能力。
- 本地批量处理图片、音频和允许的 L1 视频音轨任务。
- 正式报告导出。
- 自动云同步个人版权库元数据。
- 跨设备版权库一致性。
- L2 视频指纹存证提交和报告展示。
- 云端版权库个人视图。
- 公开权利元数据导出。

关键指标：

- 登录后默认 `auto_cloud_vault`。
- 用户可暂停自动同步为 `manual_local_only`，但本地队列、云端版权库和本地版权库不被删除。
- 同步只传白名单元数据。

### 3.3 Studio

Studio 是小团队协作层。

北极星能力：

- 包含 Creator 全部能力。
- 团队空间。
- 成员权限。
- 团队共享版权库。
- 团队审计日志。
- 团队报告。
- 团队级公开元数据管理。
- 团队维权证据包整理。

关键边界：

- 团队共享默认仍只共享版权元数据，不共享原始媒体、本地路径或保护副本字节。
- 成员权限必须影响查看、编辑、报告导出、公开元数据导出和审计可见性。
- 团队报告必须标明记录来源、成员身份、操作时间和授权边界。

### 3.4 Enterprise

Enterprise 是受控客户集成层。

北极星能力：

- 包含 Studio 全部能力。
- 受控只读公开权利扫描 API。
- API key、scope、quota、审计、限流和可信代理指纹。
- 客户开通流程、SLA、对账和支持流程。
- 生产 C2PA 证书链 / TSA 配置和轮换。
- SDK 外部分发和版本兼容策略。
- 合同级云视频能力预留。

关键边界：

- 外部 API 默认只读。
- 所有公开权利结果固定不能返回法律授权结论。
- 客户自助 key 管理、quota 管理、写入型 API、媒体扫描平台化能力必须单独评审。
- Enterprise 能力不能进入 `watermark-core` 主链路；`watermark-core` 只负责正式盲水印算法与 payload。

## 4. 媒体能力北极星

### 4.0 目标支持格式总表

| 媒体类型 | 北极星目标支持格式 | 未来候选格式 | 明确不承诺 |
| --- | --- | --- | --- |
| 图片 | PNG、JPEG / JPG、WebP、BMP | TIFF、GIF、HEIC、AVIF | 其他未列出图片容器 |
| 音频 | WAV、MP3、FLAC、OGG、M4A、AAC（优先以 M4A / MP4 承载） | ADTS、其他未列出音频容器 | 其他未列出音频容器 |
| 视频 L1 音轨 | MP4、MOV、WEBM、AVI、MKV、M4V | 其他未列出视频容器 | 其他未列出视频容器 |
| 视频 L2 指纹存证 | MP4、MOV、WEBM、AVI、MKV、M4V | 其他未列出视频容器 | 其他未列出视频容器 |
| 视频 L3 画面盲水印 | 仅 staged 评估的 MP4、MOV、WEBM、AVI、MKV、M4V 样本池 | 720p / 1080p / 2K 扩展样本池 | 不承诺任何用户可售容器集合 |

说明：

- 正式支持格式必须满足当前 release gate。
- 未来候选格式可以进入 staged / 只读 QA，但不能出现在用户承诺、套餐权益或正式报告中。
- 明确不承诺项一律不能写成“支持中”或“即将支持”。

### 4.1 图片

当前可承诺基础：

- 正式图片水印写入和验证使用 `watermark-core`。
- 跨端互验覆盖 PNG / JPEG / WebP 输入。
- 保护副本以安全输出格式表达，不承诺保留原扩展名。
- 图片北极星按素材类型分层管理，优先保护有价值图片，样本池至少覆盖照片、插画、UI 截图、低纹理图和文字图。
- 图片正式入口仅承诺 PNG、JPEG / JPG、WebP、BMP 四类容器。
- 图片正式门槛要求最小支持分辨率为短边 >= 720px 且总像素 >= 0.5MP，低于门槛明确拒绝。
- 图片注入后必须通过视觉无损验证，失败时只能给出风险或拒绝，不能把近似结果包装成已无损。

北极星支持矩阵：

| 类型 | 北极星目标 | 验收要求 |
| --- | --- | --- |
| PNG | 默认支持写入、读取、公开元数据嵌入 | 桌面 / Android / iOS 双向互验，V3/39 默认读写 |
| JPEG / JPG | 支持输入，输出保护副本，支持公开元数据嵌入副本 | 质量门禁、EXIF/XMP 边界、跨端互验 |
| WebP | 支持输入，输出保护副本 | 跨端互验、透明通道策略明确 |
| BMP | 正式支持输入，输出保护副本以 PNG 为主 | 北极星标配，不再写入“扩展输入” |
| TIFF / GIF | 可作为扩展输入 | 必须先有 fixture、失败文案和输出策略；不得默认写进当前承诺 |
| HEIC / AVIF | 未来输入候选 | 依赖平台解码、授权和质量门禁 |

图片质量指标，北极星目标：

| 指标 | 目标 |
| --- | --- |
| 注入耗时 | 标准样本池 p50 <= 3s，超过阈值必须进入降级或明确拒绝 |
| 解析耗时 | 标准样本池 p50 <= 1s，超过阈值必须进入降级或明确拒绝 |
| 默认写入成功率 | 标准样本池 >= 99.5% |
| 默认读取成功率 | 未攻击保护副本 >= 99.9% |
| 跨端读取一致性 | 支持矩阵内 100% release gate 通过 |
| 小图拒绝准确性 | 不满足容量条件时 100% 明确拒绝，不生成假成功 |
| PSNR | 标准样本池 p50 >= 42 dB，p95 风险样本有解释 |
| SSIM | 标准样本池 p50 >= 0.985 |

鲁棒性目标：

- 基础保存、重新打开、格式内重编码后仍可读取。
- 轻度亮度、轻度噪声、轻度压缩后给出稳定验证结果或明确风险状态。
- 裁剪、缩放、旋转、镜像等场景应分为默认验证与深度取证，不混成单一承诺。

### 4.2 音频

当前可承诺基础：

- 正式音频水印写入和验证使用 `watermark-core`。
- 跨端互验覆盖 WAV、MP3、FLAC、OGG、M4A。
- AAC 的正式目标支持以 M4A / MP4 承载为主；裸 ADTS 未进入标准 fixture 前，不单独承诺。
- 音频质量必须引入 ABX 主观听感样本池，自动指标只能当门槛，不能替代人工听感验证。
- 音频注入后必须通过人类听觉无损验证，失败时只能给出风险或拒绝，不能把近似结果包装成已无损。

北极星支持矩阵：

| 类型 | 北极星目标 | 验收要求 |
| --- | --- | --- |
| WAV | 默认支持写入、读取、报告和公开元数据传播层 | 桌面 / Android / iOS 双向互验 |
| MP3 | 支持输入，归一化后写入保护副本 | 固定 fixture、声道 / 采样率策略、质量门禁 |
| FLAC | 支持输入，归一化后写入保护副本 | 固定 fixture、无损输入说明 |
| OGG | 支持输入，归一化后写入保护副本 | 固定 fixture |
| M4A | 支持输入，归一化后写入保护副本 | AAC in MP4 边界明确 |
| AAC | 正式支持，优先以 M4A / MP4 容器承载 | 裸 ADTS 先作为候选，不单独承诺 |
| ADTS | 未来候选 | 补标准 fixture 后再决定是否承诺 |

音频质量指标，北极星目标：

| 指标 | 目标 |
| --- | --- |
| 注入耗时 | 标准样本池 p50 <= 3s，超过阈值必须进入降级或明确拒绝 |
| 解析耗时 | 标准样本池 p50 <= 1s，超过阈值必须进入降级或明确拒绝 |
| 默认写入成功率 | 标准样本池 >= 99.5% |
| 默认读取成功率 | 未攻击保护副本 >= 99.5% |
| 跨端读取一致性 | 支持矩阵内 100% release gate 通过 |
| 最小时长规则 | 低于产品阈值时 100% 明确拒绝 |
| SNR | 标准样本池 p50 >= 38 dB |
| LUFS 变化 | p95 绝对变化 <= 1.0 LU |
| 峰值变化 | 不新增 clipping；峰值差异受门禁记录 |
| ABX 样本池 | 覆盖 speech、music、mixed、edge case 四类样本 |

音频策略要求：

- 桌面与移动端必须保持同一产品语义。
- 转码层可以不同，但进入 `watermark-core` 的能力边界必须可解释、可测试。
- 声道、采样率和编码转换必须在用户可见文案中表达清楚。
- 30 秒以下音频仍应明确拒绝或降级，不进入正式保护承诺。

### 4.3 视频

视频能力必须分层表达。

| 层级 | 定义 | 北极星目标 | 当前包装规则 |
| --- | --- | --- | --- |
| L1 视频音轨水印 | 对视频中的音频轨写入音频盲水印 | 本地可用、可验证、可报告、可跨端互验；正式容器为 MP4 / MOV / WEBM / AVI / MKV / M4V，支持多音轨容器，静音视频和极短视频明确拒绝 | 可对用户表达为视频音轨水印 |
| L2 视频指纹存证 | 生成不可逆画面指纹并提交云端存证 | Creator 及以上可提交，双端可查看，报告可展示；正式容器为 MP4 / MOV / WEBM / AVI / MKV / M4V，定义相似性阈值和争议处理流程 | 不能说成盲水印命中 |
| L3 视频画面盲水印 | 对视频画面写入和读取盲水印 | 未来高阶商业能力，不是长期研发储备；当前 staged 只作为发布前研发和质量门禁，样本池先以 MP4 / MOV / WEBM / AVI / MKV / M4V 为主 | 当前只能内部 staged |

L1 北极星指标：

| 指标 | 目标 |
| --- | --- |
| 音轨抽取成功率 | 标准 MP4/MOV/WEBM/AVI/MKV/M4V 样本池 >= 99% |
| 写入后回读成功率 | 标准样本池 >= 99% |
| 成品视频音轨注入 | p50 <= 3s |
| 成品视频音轨解析 | p50 <= 1s |
| 计费 | 本地 L1 不扣 `video_minutes` |
| 明确拒绝 | 静音视频、极短视频和低于 30 秒视频 100% 明确拒绝 |

L2 北极星指标：

| 指标 | 目标 |
| --- | --- |
| 指纹包生成成功率 | 标准 MP4/MOV/WEBM/AVI/MKV/M4V 样本池 >= 99% |
| 指纹包隐私 | 不包含原始视频、可还原帧、本地路径 |
| 云端存证成功率 | 正常网络下 >= 99.5% |
| 存证报告字段完整率 | 100% 包含 notary id、fingerprint root、bundle hash、scene count、elapsed time、receipt signature |
| 移动端展示 | 同步后只读展示，字段与桌面一致 |
| 相似性阈值 | < 0.85 不命中，0.85 - 0.92 进入争议队列，>= 0.92 记为高置信相似证据 |
| 争议处理 | 必须进入人工复核，依据 notary id、bundle hash、scene count、原始登记记录和补充样本池判断，不自动输出法律结论 |

L3 北极星准入条件：

- 画面盲水印算法必须位于 `watermark-core`。
- 云端只能包装 `watermark-core`，不能成为第二套算法源。
- 必须有 720p / 1080p / 2K release 样本池。
- 必须有 VMAF / SSIM / PSNR 或等价视频质量门禁。
- 必须有平台二压矩阵、失败归因和成本模型。
- 必须有客户端自检、云任务状态、取消 / 失败不扣费、成功后入账。
- 必须完成桌面端、Android、iOS、后端或云任务之间的跨端互验。
- 必须在发布前完成生产 C2PA 证书链和 TSA 配置，不得把 staging trust chain 当成可售信任链。
- 必须先更新 `docs/当前真实能力边界说明.md`，再进入 UI、订阅权益或销售文案。

## 5. Payload 与登记能力

北极星目标：

- V3/39 最小锚点是图片、音频和 L1 视频音轨默认媒体 payload。
- V2/119 只保留为显式迁移、回滚、历史读取和修复工具链。
- 媒体内只保存可验证锚点，不保存完整权利声明。
- 完整权利声明、训练许可、作品来源、版本链、登记证明和公开元数据由版权库、云版权库、registry 和公开元数据层承接。

关键验收：

| 能力 | 指标 |
| --- | --- |
| 新写入默认 V3 | 正式路径 100% V3/39，除非显式 rollback |
| V2 回滚 | 只能通过 `force_v2_rollback` / `embed_v2` / `extract_v2` 等显式工具 |
| 版权编号唯一性 | 同一创作者连续写入不同作品不得复用 UID |
| 离线兜底 | 后端不可用时仍可本地写入，状态为 pending registration |
| 云同步补登记 | Creator 及以上同步前自动 confirm / reconcile |
| 登记状态表达 | 只有 server_confirmed / offline_confirmed 可称为登记确认 |
| 冲突处理 | 同 UID 不同哈希不静默覆盖，进入仲裁或重新签发 |
| 生产 C2PA / TSA | 发布前硬门槛，未完成时只能作为 staging 证据 |

## 6. 版权库与云版权库

### 6.1 本地版权库

北极星能力：

- 支持图片、音频、L1 视频音轨、L2 视频指纹存证记录。
- 支持搜索、筛选、排序、详情、版本链、登记状态、验证状态和同步状态。
- 支持复制摘要、导出正式报告、导出公开元数据。
- 支持历史记录修复、重新签发、登记仲裁。

### 6.2 云端版权库

北极星能力：

- Creator 及以上自动同步个人版权库元数据。
- 云端版权库 UI 第一版信息架构以个人库优先，团队共享库其次，Enterprise 只读集成置后。
- Studio 支持团队共享版权库。
- Enterprise 支持合同级审计、导出和只读集成。
- 云端版权库 UI 能查看同步记录、冲突状态、登记状态、公开元数据状态和报告状态。

当前状态说明：

- 云端版权库数据同步是商业化基础能力。
- 云端版权库独立 UI 仍是待办。
- 本文只登记目标，不在本任务实现 UI。
- Studio 团队共享版权库不支持跨成员记录转让、归档或撤销，涉及所有权变更必须通过新记录或新版本链表达。
- Enterprise 外部 API 长期保持只读，不规划写入型 registry 管理 API。

云端版权库同步白名单：

- 版权编号、版本、父编号。
- 媒体类型、标题、安全文件名。
- 原作品摘要、保护副本摘要、保护副本名称。
- 写入后验证状态和验证说明。
- 登记状态、登记收据、签发模式。
- payload protocol、payload bytes、payload auth status。
- 作品来源、创作方式、人工编辑、真实性、训练许可和自定义版权声明。
- 报告购买授权状态。
- L2 不可逆指纹存证字段。
- 同步状态、冲突状态和审计摘要。

同步禁止字段：

- 原始媒体字节。
- 保护副本字节。
- 原始媒体本地路径。
- 保护副本本地路径。
- 本地 bundle 路径。
- 可还原视频帧或音频片段。
- creator seed 明文。
- API key 明文或 key hash。

## 7. 公开权利、C2PA 与声明传播

北极星目标：

- 媒体 payload 只做可验证锚点。
- registry 保存 active rights manifest。
- 公开元数据层负责传播作品声明、训练许可和授权边界。
- C2PA / CAWG / IPTC / XMP / JSON-LD 是公开传播层，不是生产可信授权结论本身。
- 生产可信 C2PA 必须依赖正式证书链、私钥托管、TSA、轮换和 staging QA。

关键指标：

| 指标 | 目标 |
| --- | --- |
| `legalConclusion` | 所有公开查询、SDK、Enterprise API 固定 false |
| UID 一致性 | 嵌入公开元数据前 100% 校验 registry UID 与本地记录 UID |
| 生产证书状态 | 未配置证书时必须标记非公开信任锚 |
| 元数据导出 | JSON、PNG/JPEG 嵌入副本、WAV/MP4/M4A/MOV 容器传播层逐步覆盖 |
| iOS 覆盖 | iOS 分享面板、文件名、内容校验必须单独 QA |

禁止表达：

- 系统自动确认训练许可。
- 系统给出法律授权判断。
- ephemeral signer 等于生产 C2PA trust chain。
- C2PA manifest 等于法院认可证据。

## 9. 性能与可靠性指标总表

这些是北极星目标，不是当前承诺。进入对外 SLA 前必须有 release 样本池、运行态 QA 和回归门禁。

| 领域 | 指标 | 北极星目标 |
| --- | --- | --- |
| 注入 / 写入 | 标准样本池 p50 / p95 | <= 3s / release 样本池另定 |
| 解析 / 验证 | 标准样本池 p50 / p95 | <= 1s / release 样本池另定 |
| 图片质量 | 类型分层样本池 | 照片、插画、UI 截图、低纹理图、文字图都必须能分别进入门禁 |
| 音频质量 | ABX 样本池 | Speech、music、mixed、edge case 四类样本都必须覆盖 |
| L1 视频音轨 | 标准视频样本池 p50 / p95 | 30 秒以上、带音轨、非静音样本可用；静音 / 极短直接拒绝 |
| L2 指纹包 | 3 分钟视频 p50 / p95 | <= 60s / <= 180s |
| 云同步 | 正常网络端到端延迟 | p50 <= 5s，p95 <= 30s |
| 云同步重试 | 临时失败恢复 | 自动退避，用户可手动重试 |
| 登录 | auth/session 成功响应 | p95 <= 2s，不含短信 / 邮件供应商延迟 |
| 报告导出 | 单条记录 | p95 <= 5s |
| UI 反馈 | 处理启动反馈 | 100ms 内进入明确状态 |
| 崩溃率 | 客户端会话 | < 0.1% |
| 数据丢失 | 本地成功记录 | 0 容忍 |

## 14. 已确认决策

这份北极星文档的第一版决策已收口，后续主要细化 release 样本池和 QA 门禁实现。

1. 图片按素材类型分层，优先保护有价值图片，覆盖照片、插画、UI 截图、低纹理图和文字图。
2. 图片最低支持分辨率和格式要明确，正式容器先收敛到 PNG、JPEG / JPG、WebP。
3. 图片注入后必须做视觉无损验证。
4. 音频必须引入 ABX 主观听感样本池，并做人类听觉无损验证。
5. L1 视频音轨支持多音轨，但静音视频、极短视频和低于 30 秒视频明确拒绝。
6. L2 指纹存证定义相似性阈值和争议处理流程。
7. L3 保持未来高阶商业能力，不降级为长期研发储备。
8. 云端版权库 UI 第一版个人库优先。
9. Studio 团队共享版权库不支持跨成员记录转让、归档和撤销。
10. Enterprise 外部 API 长期保持只读。
11. 性能目标不按设备档位拆分，统一要求注入 <= 3s、解析 <= 1s。
12. 生产 C2PA 证书链和 TSA 是发布前硬门槛。
