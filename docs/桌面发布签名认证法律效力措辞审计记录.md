# HiddenShield 桌面发布签名、认证与法律效力措辞审计记录

更新时间：2026-07-26

状态：桌面 `v0.1.3` `PASSED`

## 1. 审计结论

本轮只审计并修正桌面正式 UI、版权报告、帮助中心和用户协议中的“签名 / 认证 / 法律效力”表述，不实施公共信任层，不修改 Watermark ID、V3 / 39-byte payload、HMAC auth tag、registry schema、API、数据库或共享水印算法。

公共信任层继续保持：

```text
suspended_by_user
```

本轮确认：

- `payloadAuthStatus=verified` 只表示载荷认证标签符合当前 HiddenShield 编解码认证规则。
- “版权编号签发”只表示 Watermark ID 的生成、预留、分配或重新分配。
- Manifest 摘要匹配只表示报告包文件完整性匹配。
- RFC 3161 token、网络授时和记录创建时间属于不同时间材料；未完成独立验签时不得统一描述为可信时间证明。
- 上述状态均不等于发行方数字签名、实名认证、法定权属确认、司法鉴定或司法采信。

## 3. 保留的技术术语

以下术语可以继续保留，但必须保留上下文：

- `RFC 3161`、TSA、token、证书链验签：只描述实际时间戳协议或校验路径。
- Authenticode：只描述 Windows 二进制签名状态。
- 离线许可证签名：只描述许可证合同的公钥验签。
- 版权编号签发：只描述 Watermark ID 生成或分配，不描述 issuer 数字签名。
- 数字签名：仅用于明确说明“未接入”“未验证”或真实存在的具体签名对象。
