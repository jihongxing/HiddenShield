# HiddenShield 盲水印无感测试计划

更新时间：2026-07-02

本文用于固化图片、音频和视频盲水印注入后的感知质量测试。目标不是证明“绝对无感”或“零影响”，而是在明确样本池、设备、阈值和盲测规则下，证明保护副本对普通人类视觉 / 听觉难以稳定分辨，同时仍能读回同一 `watermarkUid` 和 V3/39 payload。

## 1. 发布原则

每个样本必须同时满足两类门禁：

| 门禁 | 必须通过的内容 | 失败含义 |
| --- | --- | --- |
| 可提取性 | 写入后能读回同一 `watermarkUid`、`payloadProtocolVersion=3`、`payloadBytesLength=39`、`payloadAuthStatus=verified` | 扰动可能很小，但保护不可用 |
| 感知质量 | 自动指标过线，人工 ABX 不能稳定识别保护副本 | 水印能读回，但用户可能看得出或听得出 |

自动指标是发布阻断门槛，人工 ABX 是“无感”表述的补证。任何一类失败都不得对外宣称“无感”“不可见”“不可闻”。

## 2. 样本池

### 2.1 图片样本池

| 分组 | 最低数量 | 目的 |
| --- | ---: | --- |
| 人像 / 自然照片 | 10 | 覆盖真实照片、肤色、自然渐变和高频纹理 |
| 低纹理 / 渐变 / 纯色背景 | 6 | 捕捉天空、墙面、纯色图中的可见扰动 |
| 插画 / 海报 / 色块图 | 6 | 捕捉大色块、锐利边缘和线稿风险 |
| UI / 文字截图 | 6 | 捕捉文字边缘、细线、图标和压缩伪影 |
| 暗光 / 高 ISO / 高细节 | 6 | 捕捉噪声区和高频区扰动 |
| 最小尺寸边界样本 | 4 | 验证接近容量边界时的视觉质量 |

输入格式至少覆盖 PNG / JPEG / WebP。比较对象必须是同一输出链路生成的控制副本和保护副本；有损格式不得直接拿原始文件与保护副本比较。

### 2.2 音频样本池

| 分组 | 最低数量 | 目的 |
| --- | ---: | --- |
| 人声 / 播客 / 旁白 | 8 | 捕捉清晰度、齿音和语音底噪 |
| 流行音乐 / 高动态音乐 | 8 | 捕捉宽频内容、瞬态和响度变化 |
| 安静 / 稀疏 / 古典片段 | 6 | 捕捉低能量段噪声底抬升 |
| 噪声环境 / 现场录音 | 6 | 捕捉复杂噪声底下的水印扰动 |
| 单声道 / 立体声 | 各 4 | 覆盖声道处理边界 |
| MP3 / FLAC / OGG / M4A 输入 | 各 4 | 覆盖正式归一化路径 |

音频比较前必须统一采样率、声道、位深或 float 表示。30 秒以下音频不进入用户承诺门禁，只作为观察项；L1 视频音轨可按短视频模式单独测试，但不能替代完整音频门禁。

### 2.3 视频样本池

视频分三类处理：

| 类型 | 是否进入当前用户无感门禁 | 测试方式 |
| --- | --- | --- |
| L1 视频音轨水印 | 是 | 比较成品视频中抽取出的控制音轨和保护音轨 |
| L2 视频指纹存证 | 不适用 | L2 不注入盲水印，不做无感测试 |
| L3 视频画面盲水印 | 仅内部 staged | 用 VMAF / 视频 PSNR / 视频 SSIM 和人工视觉 ABX 做内部研究，不进入用户承诺 |

L1 样本至少覆盖横屏、竖屏、音乐背景、人声口播和混合音轨。L3 内部样本至少覆盖 16:9、9:16、3:4、低纹理、高细节、字幕密集、真实拍摄运动和平台二压 profile。

## 3. 自动指标与阈值

### 3.1 图片阈值

| 策略 | 最低 PSNR | 最低 SSIM | 阻断规则 |
| --- | ---: | ---: | --- |
| Forensic 默认 | >= 38 dB | >= 0.990 | 任一样本低于阈值即阻断 full gate |
| Balanced 候选 | >= 42 dB | >= 0.995 | 任一样本低于阈值即阻断候选策略发布 |

诊断指标必须记录最大通道差异、MAE、95 分位像素差和差异热力图。热力图只用于定位问题，不单独作为发布通过依据。

### 3.2 音频阈值

| 策略 | 最低 SNR | Integrated LUFS 差异 | 峰值差异 | 新增 clipping |
| --- | ---: | ---: | ---: | ---: |
| Forensic 默认 | >= 44 dB | <= 0.5 LU | <= 0.8 dB | 0 |
| Balanced 候选 | >= 50 dB | <= 0.3 LU | <= 0.5 dB | 0 |

静音段不参与整体 SNR 主判定，但必须记录静音段噪声底抬升。如果原音频已有 clipping，只允许保留原有 clipping，不允许保护副本新增 clipping sample。

### 3.3 视频阈值

L1 视频音轨使用音频阈值，且必须比较成品视频抽取音轨。

L3 视频画面只作为内部 staged 指标：

| 策略 | VMAF 下降 | 最低视频 PSNR | 最低视频 SSIM | 边界 |
| --- | ---: | ---: | ---: | --- |
| Forensic 默认 | <= 2.0 | >= 37 dB | >= 0.990 | 仅内部研究 |
| Balanced 候选 | <= 1.0 | >= 40 dB | >= 0.995 | 仅内部候选 |

L3 即使通过 VMAF，也必须同时满足 payload 一致性、自检 confidence 和 L3 release 样本池阈值；VMAF 只证明画质，不证明水印能力可售。

## 4. ABX 人工盲测表格

ABX 测试必须双盲：测试者不知道 A/B 哪个是保护副本，记录者也不得在测试中提示。图片使用正常观看距离和放大诊断两轮；音频使用耳机和外放两轮；视频使用正常观看和全屏观看两轮，逐帧暂停只作为研发诊断，不作为普通用户无感结论。

| runId | mediaType | sampleId | profile | device | environment | trial | A | B | X | answer | correct | confidence_1_5 | perceivedDifference | notes |
| --- | --- | --- | --- | --- | --- | ---: | --- | --- | --- | --- | --- | ---: | --- | --- |
|  | image |  |  | monitor / phone | normal-distance / zoom-diagnostic | 1 | original/protected | original/protected | A/B | A/B | true/false |  | noise / edge / banding / none |  |
|  | audio |  |  | headphones / speaker | quiet-room / office | 1 | original/protected | original/protected | A/B | A/B | true/false |  | hiss / sibilance / loudness / none |  |
|  | video_audio_track |  |  | headphones / speaker | quiet-room / office | 1 | original/protected | original/protected | A/B | A/B | true/false |  | loudness / distortion / none |  |
|  | video_visual_staged |  |  | monitor / phone | normal / fullscreen | 1 | original/protected | original/protected | A/B | A/B | true/false |  | flicker / block / subtitle-edge / none |  |

通过规则：

- 单个测试者单组正确率超过 70% 时，该组进入复核。
- 5 人以上同组平均正确率超过 60% 时，该组不得宣称无感。
- 任一测试者明确指出稳定可复现的视觉 / 听觉差异时，即使正确率未过线，也必须进入研发诊断。
- ABX 原始记录必须随自动报告归档，不能只保留汇总结论。

## 5. 自动化 full gate 输出


输出目录：

```text

  quality-full-gate.json
  quality-full-gate.md
  images/<sample-id>/control.png
  images/<sample-id>/protected.png
  audio/<sample-id>/control.wav
  audio/<sample-id>/protected.wav

  abx/video_audio_track_abx_trials.csv

```

`quality-full-gate.json` 最少包含：

| 字段 | 说明 |
| --- | --- |
| `gate` | `watermark:quality-gate:full` |
| `scope` | `perceptual_full_gate` |
| `payloadProtocolVersion` | 当前应为 `3` |
| `payloadBytesLength` | 当前应为 `39` |
| `extractPassed` | 样本是否读回同一水印 |
| `qualityPassed` | 自动指标是否过线 |
| `releaseBlockingReason` | `none` / `extract_failed` / `psnr_below_threshold` / `ssim_below_threshold` / `snr_below_threshold` / `lufs_delta_above_threshold` / `peak_delta_above_threshold` / `new_clipping` / `vmaf_delta_above_threshold` |

| `videoVisualStaged` | L3 视频画面 staged 状态，必须链接 `watermark:l3-video-visual-release-gate`、未来 VMAF / video PSNR / video SSIM 指标和 `abx/video_visual_staged_abx_trials.csv` |

## 6. 通过 / 阻断规则

full gate 通过条件：

1. 所有图片、音频、L1 视频音轨样本可读回同一 V3/39 payload。
2. 所有图片自动指标满足 Forensic 默认阈值。
3. 所有音频和 L1 视频音轨自动指标满足 Forensic 默认阈值。
4. ABX 模板已生成，并完成抽样人工测试后未出现稳定可分辨结果。
5. L2 视频指纹存证必须记录为 `videoFingerprintNotary.status=not_applicable_no_media_mutation`，不进入 PSNR / SNR / VMAF / ABX 指标。
6. L3 视频画面结果只记录为 `videoVisualStaged.status=internal_staged_only` 或 `delegated_internal_staged`，不进入用户承诺。

阻断条件：

- 任一样本提取失败。
- 任一样本自动指标低于阈值。
- 任一类别 ABX 平均正确率高于 60%。
- 发现可稳定复现的视觉 / 听觉差异，但未完成归因和修复。
- 试图把 L3 视频画面 staged 指标写入用户承诺、订阅权益或正式报告。

## 7. 对外表述边界

- “在当前样本池和阈值下，保护副本未出现稳定可感知差异。”

- “完全无损。”
- “绝对无感。”
- “所有素材不可见 / 不可闻。”

## 9. 2026-07-26 单人本地感知质量实验室

- 新增独立工具 `tools/perceptual-quality-lab`，只作为内部筛查和诊断入口，不属于主程序正式功能。
- 图片模式提供并排、同步缩放 / 拖动、分割、闪烁和差异热力图；热力图只定位差异，不能作为正常观看结论。
- 音频模式通过 FFmpeg 解码并在 `±250 ms` 范围内估计编码延迟，生成共同 10 秒试听窗口；采样率、声道或时长超出容差时只允许诊断，不形成正式阈值结论。
- 快速 ABX 为 10 轮，正式单人 ABX 为 20 轮；X 的 source / candidate 身份各占一半，每轮不反馈正确性，结束后计算正确率和单侧二项分布 p 值。
- 单人结论规则：正确率 `<= 60%` 且不显著时只写“未观察到稳定可区分证据”；`60%–70%` 为不确定；`> 70%`、`p < 0.05` 或测试者记录稳定可复现差异时进入复核。
- 单人实验室不保存历史、不自动导出报告；它不能替代本计划要求的 5 人以上同组 ABX 原始记录。
- 验证：前端类型检查与生产构建通过，ABX 随机平衡 / 显著区分 / 机会水平测试通过 `3/3`；Rust 对齐 / 波形测试通过 `2/2`。
- release/full 回归仍为阻断：release 的 `low-texture` SSIM `0.982920 < 0.985`；full 中 `low-texture`、`ui-text`、`portrait-skin`、`dark-high-iso`、`fine-detail`、`small-boundary` 图片以及 `field-noise` 音频未过线。`field-noise` 本轮 SNR 为 `12.9879 dB`，提取置信度仍为 `1.000000`。

2. 固定 gate 基准 artifact，修复 `low-texture` 等当前客观指标阻断后再评估发布状态。
