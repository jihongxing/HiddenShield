# HiddenShield 商业套餐与权益全局语义设计

状态：`已定稿；后续商业化、云版权库和支付工作必须遵守`

生效日期：2026-07-31

关联决策：`docs/adr/0001-商业套餐与能力权益解耦.md`

## 1. 决策摘要

当前桌面端不存在 Free / Creator / Studio / Enterprise 四档可售套餐，也不应把它们继续设计为一条升级阶梯。

全局模型改为：

1. **基础状态**：未付费桌面产品状态。
2. **图片 / 音频年费**：当前唯一用户可见的付费桌面套餐，其年度授权内含本地批量和 metadata-only 云同步。
3. **单份报告商品**：与记录或案件绑定的一次性购买，不改变年度授权状态。
4. **未来能力权益**：团队工作区、API、云端批量、云视频等由独立 feature、scope、额度和合同控制。
5. **组织产品线**：团队工作区和企业集成是未来合同产品，不是桌面套餐的第三、第四档。

价格、促销、支付渠道和地区税务尚未进入当前定稿；不得在代码、UI 或对外文案中虚构价格。

## 2. 当前可见产品目录

| 类别 | 标准名称 | 当前状态 | 核心权益 | 明确不包含 |
| --- | --- | --- | --- | --- |
| 基础状态 | `未付费` | 已发布桌面口径 | 单文件图片 / 音频写入与验证、本地版权库 | 批量、云同步、团队、API、云视频、正式报告导出 |
| 付费套餐 | `图片 / 音频年费` | 已发布桌面口径 | 图片 / 音频本地批量处理、metadata-only 自动云同步；有效期、试用、宽限和到期按年度授权生命周期处理 | 正式报告、团队、API、云视频 |
| 单份报告商品 | `版权详细报告` | 商品合同已有，真实支付仍受现有发布边界限制 | 对一条版权记录的报告授权 | 改变年度授权、开通云能力或团队能力 |
| 单份报告商品 | `维权证据包` | 商品合同已有，真实支付仍受现有发布边界限制 | 对一个案件 / 证据包的报告授权 | 法律结论、公证、鉴定或改变其他权益 |

当前桌面 UI 只能使用“未付费”“图片 / 音频年费”“单份报告购买”等名称；“年度授权”只用于描述年费的试用、激活、宽限、到期、续费和撤销状态，不得作为第三种套餐名。不得重新展示 Creator、Studio、Enterprise 作为套餐名。

## 3. 未来能力产品化

以下是未来独立能力权益，不是新的桌面层级。年度授权已经内含 `batch_processing` 与 `cloud_sync`；下列能力不随年度授权自动开放：

| 能力产品 | 规范 capability | 授权要素 | 当前边界 |
| --- | --- | --- | --- |
| 团队工作区 | `team_workspace` | 组织、席位、角色、共享库 scope、审计 | 未开放；不支持跨成员转让、归档或撤销 |
| 企业集成 | `api_access` | 合同、只读 scope、credential、限流、审计 | 未开放；不提供写入型 registry 管理 API |
| 云端批量 | `cloud_batch_processing` | 单位额度、队列、区域、有效期 | 未开放 |
| 云端视频 | `cloud_video_processing` | 分钟 / 任务额度、队列、受控上传、成功扣量 | 未开放；不得把内部 L3 测试包装为可售能力 |
| 正式报告导出 | `report_export` | 记录 / 案件 scope 或明确服务授权 | 不从年度授权自动推导 |

产品组合的规则：

- 图片 / 音频年费的有效年度授权固定授予 `batch_processing=true` 与 `cloud_sync=true`；它可以与任意未来能力权益并存，但不会自动授予团队、API、云端批量或云视频能力。
- 组织产品线可为拥有年度授权的成员配置，也可按合同单独配置；组织身份不改变个人本地基础能力。
- 所有付费、试用、宽限、到期、退款、撤销和额度均必须落到具体商品或 capability entitlement，不允许只依据“用户属于某一档”判断。

## 4. 领域模型和授权规则

### 4.1 必须分开的四个概念

| 概念 | 作用 | 示例 |
| --- | --- | --- |
| 产品 / 商品 | 用户购买或合同交付的对象 | 图片 / 音频年费、版权详细报告、团队工作区 |
| 授权状态 | 该商品当前是否有效 | `free`、`trial`、`active`、`grace`、`expired` |
| 能力权益 | 一项操作是否允许 | `batch_processing=true`、`cloud_sync=true`、`team_workspace=true` |
| scope / 额度 | 权益允许在哪些对象及多少用量上执行 | account、workspace、record、organization、minutes |

授权判断规范：

1. 必须读取目标 capability entitlement 与必要 scope；当前图片 / 音频年费的有效年度授权是 `batch_processing` 与 `cloud_sync` 的规范授权来源。
2. 必须校验授权状态、有效期、撤销状态和额度。
3. 仅在兼容读取时可读取 legacy plan code。
4. 不得仅凭 `plan_code`、展示名称、前端按钮状态或历史用户类型授予能力。

### 4.2 既有字段的兼容映射

| 既有值 | 迁移后语义 | 处理规则 |
| --- | --- | --- |
| `plan_code=free` | `base_unpaid` | 继续读取；用户可见统一显示“未付费” |
| `plan_code=creator` | `image_audio_annual` 的历史技术别名 | 继续读取；用户可见统一显示“图片 / 音频年费”；有效年度授权规范映射为 `batch_processing=true` 与 `cloud_sync=true`，但不得据此开放报告、团队、API 或视频 |
| `productCode=creator_offline` | 年度授权的离线许可证兼容商品码 | HSLIC1 v1 不改；后续新 schema 才可引入新商品码 |
| `plan_code=studio` | 历史 / 内部兼容 profile | 不得在新桌面购买、注册、帮助或销售文案中出现；后续迁移到组织 capability entitlement |
| `plan_code=enterprise` | 历史 / 内部兼容 profile | 不得在新桌面购买、注册、帮助或销售文案中出现；后续迁移到合同组织产品与 `api_access` scope |

迁移期间必须保留 API / 数据库字段的向后兼容，但新代码要优先输出显式 feature map、scope 和产品显示名。任何删除或重写 legacy code 的任务都必须先补跨端 fixture、数据迁移、回滚路径和合同 Gate。

## 5. 文案和 UI 规范

允许：

- `未付费`
- `图片 / 音频年度授权`
- `单份版权详细报告`
- `维权证据包`
- `云同步（图片 / 音频年度授权内含；独立云版权库 UI 尚未开放）`
- `团队工作区（未来，未开放）`
- `企业只读集成（未来，未开放）`

禁止：

- `升级到 Creator`
- `Studio 套餐`
- `Enterprise 套餐`
- `Creator 及以上`
- `所有付费用户自动拥有团队、API 或云视频`
- 使用“套餐等级”代替具体 capability entitlement

历史记录、数据库值、测试 fixture 和兼容错误码可以保留旧术语，但必须标注为 legacy / historical，且不得成为用户新入口或授权依据。

## 6. 对云版权库任务的影响

独立云版权库 UI 暂停实施，直至完成下列前置对齐：

1. 云版权库 API 明确以年度授权映射的 `cloud_sync=true` 作为个人库同步权限，而不是 `Creator 及以上` 或任意未来组织 tier。
2. 桌面、移动、后端和 mock 的 entitlement DTO 具有统一的显示名、`batch_processing`、`cloud_sync`、其他 capability、scope 与 legacy mapping。
3. `cloud:contract`、`cloud:e2e`、离线许可证合同和页面级 QA 均覆盖“未付费无云同步、年度授权含云同步、年度授权不自动等于报告 / 团队 / API / 视频”的正反向测试。
4. 用户可见云版权库价格、销售、服务期和退款口径在支付与法务 Gate 完成前继续不开放。

完成上述对齐后，独立 UI 从“Creator 个人库”改为“图片 / 音频年度授权账户的个人云版权库”再进入 Slice 1。

## 7. 执行顺序

1. **P0 术语 / 合同冻结（当前任务完成）**：更新领域词汇、ADR、路线图、能力边界和 UI 任务边界。
2. **P1 DTO 与兼容适配（2026-07-31 已完成）**：桌面、移动、后端和 mock 已统一输出 `planKey / planLabel`，保留既有 `planCode / planName` wire 字段；旧 `creator / studio / enterprise` 技术码统一归一为 `image_audio_annual / 图片 / 音频年费`。
3. **P2 授权去 tier 化**：逐项把批量、报告、云版权库、团队、API、云视频的服务端授权改为 capability + scope 判断。
4. **P3 目录与支付**：在真实支付、退款、税务、法务和地域策略完成后，配置可发布商品目录；不修改核心授权模型。
5. **P4 独立云版权库 UI**：仅在年度授权 `cloud_sync` 的 API / contract / 页面边界完成后恢复。
