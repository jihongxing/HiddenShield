## 已完成正式承诺

- 桌面端正式支持静态 PNG、JPEG、WebP 输入；图片保护副本统一输出 PNG，并保持源像素尺寸不变。
- 图片最小可处理规格由 `watermark-core` 分块容量决定；最大像素为 `100 MP`，最大文件大小为 `512 MiB`。
- 安装版资源 Gate 覆盖常规横图 / 竖图 / 方图 `9 / 9`、三格式约 `99.92 MP` `3 / 3`、精确 `512 MiB` 有效 PNG `1 / 1`，均完成写入、写后回读、独立核心读取和只读验证。
- `100 MP + 1` 与 `512 MiB + 1 byte` 均正确拒绝。
- `50–100 MP` 继续按高资源大图模式提示；最终 `9992×10000` 安装版样本产品处理约 `6.36 秒`、端到端约 `12.70 秒`、峰值工作集约 `0.70 GiB`。该单一合成资源样本不构成所有 100 MP 真实照片的时延 SLA。
- 三张安装版真实照片的 PSNR 为 `44.11–51.29 dB`、SSIM 为 `0.9951–0.9981`；每张 `16/16` 十六宫格、`36/36` 关键滑动裁切和 `8/8` 旋转/缩放/JPEG/WebP 重编码恢复全部通过。
- 34 个 Windows 内置图片源生成 PNG/JPEG/WebP 共 `102` 个干净变体，误报 `0`，平均拒绝耗时 `184 ms`、最慢 `373 ms`。
- 正式证据：`artifacts/desktop-image-resource-gate/20260722-final/summary.json`。
- 最终候选三格式冒烟：`artifacts/desktop-image-resource-gate/20260722-final-candidate-smoke/summary.json`。
- 在当前桌面音频支持范围内，`24-bit PCM WAV`、`24-bit FLAC` 和 `32-bit float WAV` 输入统一生成 WAV 保护副本，并保持源采样率、声道、整数 / 浮点类型和有效位深不变。
- 2026-07-22 安装版 Gate 覆盖上述三类输入的 mono / stereo、48 kHz、31 秒真实 fixture，共 `6 / 6` 完成写入、写后回读、独立核心读取和只读验证。
- 六个样本的输入 / 输出 PCM 样本数完全一致；包含有意水印改动后的量化统计为 `SNR 68.7–70.3 dB`。该指标用于确认没有额外格式降精度，不表示保护副本与原音频零差异。
- 正式证据：`artifacts/desktop-high-bit-depth-audio-gate/20260722-final/summary.json`。

## 明确不承诺

- 低于 `8 kHz`、高于 `48 kHz`、超过 stereo、短于 `30 秒` 或长于 `20 分钟`的音频。
- 超过 `512 MiB` 的图片或音频、超过 `100 MP` 的静态图片。
- 噪声底、环境底噪音频的感知质量。
- 图片 / 音频之外的媒体，或未列入格式范围的输入。
- 动画 PNG / WebP 的逐帧语义；当前承诺仅覆盖静态图片。
- 任何通过重采样、降声道、缩小像素尺寸或转换为另一输入格式来规避预检的处理方式。
- 将 MP3、OGG、M4A 或 FLAC 作为当前桌面保护副本输出；FLAC 仅作为后续无损容器兼容选项。

## 实现与发布规则

1. 桌面选文件时必须执行格式、容量、文件大小和时长预检，并给出对应的中文失败提示。
2. `watermark-core` 和桌面执行链必须再次执行不可绕过的规格验证；前端预检不构成安全边界。
3. 每一条候选承诺都必须有允许边界、拒绝边界、接近上限和真实文件四类 fixture。
4. 发布 Gate 必须记录输入规格、输出规格、写入耗时、回读耗时、只读验证和失败码。
5. 任一承诺在 Gate 中不可达时，先更新本文件并同步 `docs/当前真实能力边界说明.md`，再修改 UI、帮助或销售口径。
6. 高位深承诺必须持续通过位深记录、量化误差和安装版读写 Gate；`64-bit float` 必须保持明确拒绝，直到独立 Gate 通过。
