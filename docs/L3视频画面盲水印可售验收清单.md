## 3. 可售前硬门槛

L3 进入可售能力前必须全部满足：

- 样本池继续从当前 1024x1024、1280x720、608x1080、1920x1080、真实运动 fixture、字幕密集和 512x512@2fps 容量拦截边界扩展到更大真实用户 MP4 矩阵，至少覆盖更多真实拍摄机型、码率、字幕样式和长视频采样。
- 创建上传入口必须自动获得可信视频时长、尺寸和帧率；移动端已接入 MP4 可信探测，仍需在真实机型 / 真实视频样本池中持续验证探测失败时的人工确认兜底文案。
- worker 必须对运行中失败继续返回稳定失败归因；历史样本曾在 worker 阶段触发 `DCT mid-band frame bitstream exceeds block capacity`，已知 512x512@2fps / 8 帧容量不足本轮决定为产品输入限制，创建 task 阶段返回 `l3_strategy_capacity_insufficient`，不再进入 worker。
- 16:9 / 9:16 / 1080p MP4 的容量与策略预算必须继续进入独立 gate；本轮 1280x720、608x1080、1920x1080 已作为成功样本进入运行态 QA，但 512x512@2fps / 8 帧被明确限制，不能包装成任意尺寸 / 帧率均支持。
- 生产队列运行态监控、worker attempt SLA / 回滚演练、对象存储清理策略、on-call 告警 runbook、生产 observability 面板、告警平台接入、客户开通验收清单和客服失败文案矩阵已接入 `cloud-video:l3-production-ops-runtime-qa` 与 `cloud-video:ci`；当前已覆盖 queued / running / failed 快照、running lease、retryable requeue、stale attempt replay protection、fatal no-charge hold、对象保留 / 清理 / 隔离规则、告警升级动作、告警 dry-run 路由、客户开通 dry-run 和 `cloud_video_task_output_not_ready` 下载阻断。
- 客服 / 产品失败文案矩阵已覆盖 `l3_strategy_capacity_insufficient`、`manifest_invalid`、`sandbox_transcode_failed`、`core_strategy_failed`、`strategy_invalid`、`self_check_failed`、`self_check_confidence_below_threshold`、`worker_receipt_invalid` 和下载授权失败；真实生产客服知识库发布、真实告警平台配置验证、首个试点客户签字验收和更大真实用户 MP4 目录样本池仍是可售前后续项。
- `video_minutes` 必须继续只在 trusted completion succeeded 后扣费，任何普通用户 status update 不得扣费。
- 桌面 / 移动正式入口、版权库详情、正式报告、云同步和隐私边界必须继续由 `cloud-video:l3-product-flow-gate` 与 `cloud-video:l3-sellable-runtime-qa` 同跑阻断。

## 4. 当前可对内表述

可以对内表述：

- L3 已具备最小真实用户 MP4 对象上传、真实 worker succeeded、签名下载、双端入库和跨端读取证据链。
- L3 仍是 release candidate，不是 Studio / Enterprise 已可售 SLA。

禁止对外表述：

- “L3 视频画面盲水印已正式可售。”
- “任意 MP4 尺寸 / 帧率均可写入。”
- “移动端已经本地完成视频画面水印。”
- “创建任务成功即代表已扣费或已写入水印。”

## 5. 下一步

下一步把真实告警平台配置验证、首个试点客户签字验收和更长时长 / 更多真实拍摄机型 / 真实字幕样式样本池接进同一条 L3 release gate。

## 6. Production Readiness Contract

新增独立门禁：`npm run cloud-video:l3-production-readiness-contract`。

默认模式下，该门禁输出 `blocked` 报告并确认当前可售阻断项仍被文档记录，不会把 L3 误判为 ready。真正准备放宽为可售 SLA 时，必须设置 `HIDDENSHIELD_L3_REQUIRE_PRODUCTION_READY=1`，并提供以下真实 artifact：

- `HIDDENSHIELD_L3_ALERT_PLATFORM_WEBHOOK`：真实生产告警平台 HTTPS webhook。
- `HIDDENSHIELD_L3_ALERT_PLATFORM_VALIDATION_JSON`：schema 为 `l3_alert_platform_real_delivery_validation_v1` 且 `status=passed` 的真实告警投递验证 JSON。
- `HIDDENSHIELD_L3_PILOT_SIGNOFF_MD`：包含 `l3_pilot_customer_signoff_v1`、`customerAcceptedL3Mp4OnlyBoundary: true` 和 `supportAndRollbackOwnerSigned: true` 的试点客户签字记录。
- `HIDDENSHIELD_L3_REAL_USER_SAMPLE_MANIFEST`：schema 为 `l3_real_user_mp4_sample_manifest_v1`、`status=passed` 且至少 24 个真实用户 MP4 样本结果的 manifest。

该 contract 的隐私边界是 `artifact_paths_only_no_media_no_signed_url_no_local_path_payload`：只检查 artifact 路径和摘要字段，不保存媒体、对象 ref、签名 URL 或本地路径。
