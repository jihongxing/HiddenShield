## 3. 一核：内容信任引擎

### 区块标题

**数字内容身份与信任引擎**

### 一句话文案

**以“原创权利身份 + AI 来源身份”双主线，为数字内容提供统一标识、验证与可信流转能力。**

### 双主线定位

| 战略主线 | 核心问题 | 一句话文案 |
| --- | --- | --- |
| **原创内容权利身份** | 这是谁创作、保护和授权的内容？ | 为人类创作者及组织提供版权 ID、保护记录、验证证据和授权关系。 |
| **AI 生成来源身份** | 这由谁、通过什么系统、在何时生成或编辑？ | 在 AI 平台生成或编辑时写入机器可读声明、鲁棒锚点和可查询来源记录。 |

### 中央能力关键词

| 标题 | 一句话文案 |
| --- | --- |
| **多媒体可信标识** | 为原创内容和 AI 生成内容建立可持续识别的机器可读身份。 |
| **版权 ID 与来源 ID** | 分别表达原创权利关系与 AI 生成、编辑和签发来源。 |
| **Manifest 与 Evidence** | 将平台声明与可验证证据分离，形成结构化透明度记录。 |
| **元数据与鲁棒锚点** | 组合开放元数据、C2PA 兼容声明和不可感知水印锚点。 |
| **写入、读取与验证** | 连接创作或生成时标识、传播后识别与状态查询。 |
| **Registry 与 Resolver** | 保存标识状态，并为平台和公众提供统一解析入口。 |
| **证据与可信报告** | 将权利、来源和验证结果组织为可理解材料。 |
| **跨端与跨组织协议** | 让个人、团队、AI 平台和第三方使用一致的信任语义。 |

### 技术起点标注

**当前技术起点：以共享水印核心、跨端产品、版权库，以及 AI Transparency Manifest、Evidence、Registry / Resolver 体系为底座。**

### 长期边界标注

**长期目标：从“保护原创文件”和“标记 AI 生成内容”升级为统一的数字内容身份与验证网络。**

## 4. 左翼：ToC 创作者服务

### 区块标题

**ToC｜创作者版权服务平台**

### 一句话文案

**陪伴创作者完成发布前保护、长期资产管理、传播后验证和维权准备。**

### 服务模块

| 模块标题 | 一句话文案 |
| --- | --- |
| **创作前保护** | 在作品发布前完成图片、音频和未来视频的一键或批量保护。 |
| **个人版权资产库** | 持续管理作品、版本、保护记录、设备与同步状态。 |
| **验证与证据服务** | 在发生传播、争议或盗用时快速完成读取、验证和报告整理。 |
| **AI 创作透明声明** | 帮助使用 AI 工具的创作者保留生成、编辑、人工参与和来源说明。 |
| **授权与维权连接** | 连接公开验证、授权记录、平台投诉和专业维权服务。 |

### 核心用户

**摄影师、设计师、插画师、音乐人、播客与视频创作者、自媒体、AI 辅助与 AI 原生内容创作者。**

### ToC 商业模式

**低门槛工具获客，以图片 / 音频年费建立订阅收入，以报告、证据包和未来视频服务形成增值收入。**

### ToC 演进句

**从一次性处理文件，升级为同时管理原创权利与 AI 创作透明度的长期内容账户。**

## 5. 右翼：ToB 组织与平台服务

### 区块标题

**ToB｜组织与平台信任服务**

### 一句话文案

**把 HiddenShield 嵌入内容生产、AI 生成、分发、治理和透明度流程，帮助组织规模化管理内容风险。**

### 服务模块

| 模块标题 | 一句话文案 |
| --- | --- |
| **内容团队工作空间** | 为工作室、MCN 和内容团队提供共享版权库、成员权限与审计协作。 |
| **企业内容治理** | 为电商、广告、教育、媒体和品牌团队提供批量保护、渠道追踪与证据管理。 |
| **AI 生成内容标识基础设施** | 为 AI 平台提供生成时来源标识、Manifest、Evidence、监管 Profile 与审计记录。 |
| **平台 API / SDK** | 为生成平台和传播平台提供标识写入、读取、查询、验证与批量接入。 |
| **Registry / Resolver** | 为平台、下游渠道和公众提供标识状态、来源声明与撤销状态解析。 |
| **私有化与行业方案** | 为高安全、高合规客户提供私有部署、策略控制、集成实施与服务保障。 |

### 优先客户顺序

**小型内容团队 → 电商 / 广告 / 教育 / 媒体企业 → AI 生成与内容传播平台 → 高安全行业客户。**

### ToB 商业模式

**以团队席位和用量订阅建立标准收入，以 AI 标识 SDK / API、Registry 服务、私有化部署和行业项目扩大客单价。**

### ToB 演进句

**从销售个人工具，升级为同时进入组织版权工作流和 AI 平台生成链路的信任服务。**

## 6. 四阶段演进路线

### 阶段一：创作者工具

**阶段标题：找到真实付费切口**

**一句话文案：以本地优先的图片与音频保护工具进入市场，验证谁会持续使用、为什么付费。**

核心任务：

- 打磨个人保护、验证、版权库和批量工作流。
- 建立清晰的年度订阅与按份报告模式。
- 获得真实付费用户、留存和复购证据。
- 以电商、广告内容团队作为首批 ToB 设计伙伴。
- 选择首个 AI 图片平台设计伙伴，完成生成时标识 Sandbox 验证。

阶段结果：

**证明 HiddenShield 不只是可用产品，而是有人愿意付费解决的真实问题。**

### 阶段二：版权资产平台

**阶段标题：建立持续账户价值**

**一句话文案：从单次文件处理升级为跨设备、可积累、可查询的个人版权资产平台。**

核心任务：

- 建立个人云版权库和多设备连续体验。
- 沉淀作品、版本、保护、验证和报告记录。
- 发展公开验证、授权记录和维权辅助。
- 推进视频保护与高价值云端处理服务。
- 为 AI 创作者提供来源声明、人工参与说明和统一验证入口。

阶段结果：

**让用户留下的不只是文件，而是一套持续增长的数字版权资产。**

### 阶段三：组织与 AI 平台服务

**阶段标题：进入企业内容工作流**

**一句话文案：把个人能力产品化为团队协作、企业治理和 AI 生成内容透明度基础设施。**

核心任务：

- 推出团队工作空间、权限、审计和统一管理。
- 标准化电商、广告、教育和媒体行业解决方案。
- 为 AI 平台提供生成时标识 SDK / API、Manifest、Evidence 与监管 Profile。
- 为生成平台、传播平台和公众提供 Registry / Resolver 查询与验证能力。
- 建立企业定价、实施、运维、续费和客户成功体系。

阶段结果：

**形成内容团队解决方案与 AI 标识基础设施两条可重复销售的 ToB 产品线。**

### 阶段四：数字内容信任网络

**阶段标题：成为生态信任基础设施**

**一句话文案：连接创作者、企业、平台与第三方验证者，形成跨平台内容身份和信任网络。**

核心任务：

- 建立跨平台内容身份注册与解析体系。
- 连接原创权利、AI 来源、授权、传播与责任关系。
- 形成跨媒体 AI 生成内容标识、监管适配和第三方验证生态。
- 推动平台、云厂商、硬件和行业伙伴采用。

阶段结果：

**由软件产品升级为具有网络效应的数字内容信任层。**

## 7. 当前位置

### 图面标签

**YOU ARE HERE｜当前处于阶段一后半程**

### 一句话定位

**技术与产品底座已超过概念验证，当前最关键的跨越是从“完成产品”转向“证明市场与付费”。**

### 当前已形成的战略资产

- 共享水印核心和跨端工程体系。
- Windows 桌面产品与图片、音频工作流。
- 本地版权库、云同步与 Registry 技术基础。
- 报告、订阅、团队、平台接口和商业化设计储备。
- AI 生成内容标识的 Manifest、Evidence、Registry / Resolver、SDK / API 与平台接入设计资产。
- 较完整的质量 Gate、能力边界和发布治理体系。

### 当前主要缺口

- 缺少稳定的付费、留存、续费和复购数据。
- 缺少可公开引用的企业客户案例。
- 首个高频、高付费 ToB 场景仍需真实销售验证。
- AI 标识基础设施尚缺真实生成平台接入、生产凭据、外部法务签署和商业 SLA。
- 产品资产较强，但商业分发和市场牵引力仍弱。

### 当前行动焦点

**优先获得 3 家内容团队付费设计伙伴，并完成 1 家 AI 图片平台的真实 Sandbox 接入，用两类证据验证近期收入与第二增长曲线。**

## 8. 一个增长飞轮

### 飞轮标题

**内容身份与验证网络飞轮**

### 飞轮节点

1. **创作者与 AI 平台接入**
   低门槛保护工具吸引创作者，生成时标识能力吸引 AI 平台。

2. **权利与来源身份沉淀**
   原创作品权利记录与 AI 生成 Manifest、Evidence 持续积累。

3. **验证场景增加**
   分享、授权、争议、AI 透明度和平台治理产生更多验证需求。

4. **团队与平台接入**
   企业通过团队空间接入，AI 与内容平台通过 SDK、API 和 Resolver 接入。

5. **验证覆盖扩大**
   更多平台和组织能够识别、查询并解释原创权利和 AI 来源身份。

6. **保护价值提升**
   内容越容易被验证，原创保护和 AI 来源标识的采用价值越高。

7. **更多用户进入**
   更高的可信度和生态覆盖吸引更多创作者、组织与合作伙伴。

### 飞轮中心句

**原创保护与 AI 标识的写入端越多，验证网络价值越高；验证覆盖越广，平台接入需求越强。**

## 10. 正式图片的视觉层级

### 第一视觉层

观众首先看到：

1. **原创权利身份与 AI 来源身份双主线**
2. **当前位于阶段一后半程**
3. **ToC 与 ToB 共享同一个数字内容身份与信任引擎**

### 第二视觉层

观众随后看懂：

1. ToC 服务解决创作者的保护、管理、验证和维权问题。
2. ToB 服务同时解决组织版权治理与 AI 平台生成内容透明度问题。
3. 四阶段不是功能堆叠，而是商业模式逐步升级。

### 第三视觉层

观众最后发现：

1. HiddenShield 的长期壁垒不只来自算法。
2. 真正的壁垒来自原创权利身份与 AI 来源身份沉淀、工作流嵌入、验证覆盖和网络效应。
3. 当前最优先任务是市场验证，而不是继续扩展所有远期能力。
