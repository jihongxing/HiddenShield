# Phase 9 用户协议草案

生效日期：2026-06-19

本文档是 HiddenShield 正式商业化前的用户协议草案，用于统一桌面端、移动端和后端的产品口径。正式上线前仍需由法律顾问审阅。

## 1. 产品范围

HiddenShield 提供本地图片 / 音频盲水印写入与验证、本地版权库、本地批量处理、正式报告、Free 单份报告付费、云同步、Studio 团队空间预留和 L2 视频指纹存证等能力。

本地视频盲水印不属于当前本地能力。L2 视频能力是画面指纹存证和相似性验证增强，不是视频画面盲水印。L3 端云协同画面盲水印仍是未来能力。

真实收费能力仅在微信商户参数、公网 HTTPS 回调、真实订单 / 退款撤销联调和法务审阅完成后启用；未配置时，产品只能提示“支付通道尚未完成配置”。

## 2. 用户责任

用户应确保其处理、上传、同步、存证、导出的作品和资料具有合法权利基础。

用户不得使用 HiddenShield 从事侵权、伪造证据、冒用他人身份、恶意投诉、规避监管、破坏系统或其他违法违规行为。

因用户内容、使用行为或权利主张引发的争议，由用户自行承担相应责任。

## 3. 版权保护边界

HiddenShield 的水印、指纹、时间戳、报告和验证摘要是版权管理和技术辅助材料，不构成法律意见、司法鉴定意见或诉讼结果承诺。

HiddenShield 不承诺任何算法可以抵御所有攻击，也不承诺“绝对防盗”。用户在维权时仍需结合原始创作材料、发布记录、平台证据、合同、沟通记录和其他证据链。

## 4. 本地与云端边界

单文件图片 / 音频写入与验证可以本地使用。

用户启用云同步后，HiddenShield 会同步账户、工作区、设备、创作者档案、订阅权益、版权记录元数据、验证记录、审计记录和同步状态摘要。

默认不同步原始图片、加水印图片、原始音频、加水印音频、原始视频、加水印视频和本地文件路径。

## 5. 报告边界

正式报告用于整理版权记录、验证记录、水印提取结果、L2 视频指纹存证收据和相关摘要。

正式报告不包含原始媒体、加水印媒体和本地路径。报告不得被理解为司法鉴定、法律意见或平台必然采信的证明。

## 6. 订阅权益

HiddenShield 使用 Free / Creator / Studio / Enterprise 分层：

- Free：本地单文件图片 / 音频写入与验证、本地版权库；支付通道配置后可按记录购买单份版权详细报告或维权证据包。
- Creator：本地批量处理、正式云同步、订阅内正式报告、个人 L2 视频指纹存证。
- Studio：团队空间入口、成员权限模型、共享版权库模型和团队审计模型预留；真实团队管理以后续产品内说明为准。
- Enterprise：API、私有化部署、专属云端视频处理和定制支持均以后续合同、开通验收和能力边界说明为准；不包含当前未开放为可售权益的 L3 视频画面盲水印。

具体权益以产品内展示和云端权益快照为准。

## 7. 服务变更

HiddenShield 可能因安全、合规、算法升级、云服务成本、第三方服务变化或产品规划调整部分能力。重大变化会尽量在产品内或发布说明中提示。

如用户不同意变更，可以停止使用联网能力、退出账户或联系支持处理订阅问题。

## 8. 草案状态

本文档是 Phase 9 上线前草案，不替代正式法律审阅。正式收费上线前，需要与隐私政策、支付订阅条款和产品内文案保持一致。
