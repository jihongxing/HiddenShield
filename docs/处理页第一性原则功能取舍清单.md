# HiddenShield 处理页第一性原则功能取舍清单

更新时间：2026-06-26

本文档用于约束 HiddenShield “处理”页的功能边界，避免处理页继续承载旧视频转码、平台适配或泛内容管理工具的遗留心智。

处理页的第一性原则：

```text
选择作品对象
-> 写入盲水印 / 生成存证
-> 完成后验证
-> 入库
-> 报告 / 同步 / 授权
```

处理页不是素材剪辑、平台分发、画幅适配或 AI 内容检测工具。

本文件同时约束处理页完成后进入版权库、报告、同步和移动端详情页的字段模型。既然处理页不再承载平台分发心智，版权库也不能继续把“抖音 / B站 / 小红书输出”作为产品字段展示或扩展。

## 1. 核心判断

### 1.1 必须保留为主流程

这些能力直接服务版权保护主线，应作为处理页一等能力。

| 功能 | 处理方式 | 原因 |
| --- | --- | --- |
| 图片盲水印写入 | 保留为主流程 | 当前可对用户承诺，属于正式版权保护能力。 |
| 音频盲水印写入 | 保留为主流程 | 当前可对用户承诺，且与移动端同核互验。 |
| L1 视频音轨水印 | 保留为主流程，但明确是音轨 | 当前可对用户承诺，本质是音频水印复用到视频音轨。 |
| 写前预检 | 保留为主流程 | 防止重写、误写和版本链断裂。 |
| 完成后验证 | 保留为主流程 | 是版权记录可信度和入库质量的关键门槛。 |
| 版权库入库 | 保留为主流程 | 处理结果必须进入记录管理和报告链路。 |
| L2 视频指纹存证 | 保留为独立能力区 | 当前可按边界表达，但必须说明不是盲水印命中。 |

### 1.2 应降级为附属声明

这些内容有版权记录价值，但不应成为处理主流程。

| 功能 | 处理方式 | 原因 |
| --- | --- | --- |
| 作品来源声明 | 降级到折叠区或右侧上下文 | 它是创作者声明，不是写入动作。 |
| AI 辅助 / AI 生成声明 | 降级并改名 | HiddenShield 不检测 AI，只记录用户声明。 |
| 训练许可 | 保留，但归入“作品声明与授权策略” | 与版权授权和报告有价值，但不是盲水印算法步骤。 |
| 商业使用声明 | 可选保留 | 适合进入版权记录和报告，不应阻塞写入。 |
| 自定义版权声明 | 可选保留 | 适合进入版权记录和报告，默认收起。 |

推荐改名：

```text
作品声明与授权策略
```

不再使用：

```text
标记为 AI 生成内容
```

推荐字段：

| 字段 | 建议选项 | 默认值 |
| --- | --- | --- |
| 作品来源声明 | 未声明 / 人工创作 / AI 辅助 / AI 生成 | 未声明 |
| 训练许可 | 未声明 / 禁止模型训练 / 需单独授权 / 允许非商业训练 / 允许商业训练 | 禁止模型训练 |
| 内容真实性声明 | 未声明 / 虚构或合成 / 基于真实 / 创作者声明真实 | 未声明 |
| 自定义声明 | 自由文本 | 空 |

用户可见说明必须固定为：

```text
HiddenShield 不判断作品是否由 AI 生成，只记录创作者对作品来源、训练许可和授权边界的声明，并写入版权记录与报告摘要。
```

### 1.3 应从处理页主流程移除

这些功能脱离版权保护第一性原则，应从处理页主流程下线。

| 功能 | 处理方式 | 原因 |
| --- | --- | --- |
| 抖音 9:16 | 从处理页移除 | 平台画幅适配属于素材分发，不属于盲水印。 |
| B站 16:9 | 从处理页移除 | 同上。 |
| 小红书 3:4 | 从处理页移除 | 同上。 |
| 加黑边保画面 | 从处理页移除 | 属于画面再加工，会改变证据链变量。 |
| 智能裁剪填满 | 从处理页移除 | 属于素材裁剪，不属于版权保护。 |
| 优先加速 / 优先质量 | 从处理页移除或隐藏为系统策略 | 用户不应在版权保护主流程里理解编码策略。 |
| 多平台输出 | 从处理页移除 | 会把产品心智拉回分发工具。 |

## 2. 输出原则

处理页的输出原则应改为：

```text
最小必要变更
```

用户可见口径：

- 不做平台画幅适配。
- 不主动裁剪画面。
- 不提供分发平台导出预设。
- 只在写入保护副本、封装音轨或保持可验证性所需时做最小必要编码。
- 输出重点是“保护副本”和“版权记录”，不是“平台优化版”。

## 3. 建议的新处理页结构

### 3.1 主舞台

```text
文件选择
当前对象摘要
能力识别
写前预检
主动作
进度 / 完成后验证
入库结果
```

### 3.2 能力识别

根据文件类型自动展示：

| 文件类型 | 展示能力 |
| --- | --- |
| 图片 | 图片盲水印写入 |
| 音频 | 音频盲水印写入，30 秒以上规则 |
| 视频 | L1 视频音轨水印；L2 视频指纹存证按权益显示；L3 不开放 |

### 3.3 右侧上下文

右侧上下文面板展示：

- 当前文件名、类型、大小、时长。
- 写前预检状态。
- 是否已有版权记录。
- 当前输出策略：最小必要变更。
- 作品声明与授权策略摘要。
- 下一步动作。
- L1 / L2 / L3 能力边界。

## 4. 实施建议

### Phase A：UI 下线分发适配

- 移除处理页里的抖音 / B站 / 小红书平台卡。
- 移除“画面”和“模式”两个选择器。
- 主按钮改为“生成保护副本”或“写入视频音轨水印”。
- 文案补“最小必要变更”原则。

### Phase B：重构 AI 标记为声明策略

- 将 `AIContentMarker` 改名或重构为 `WorkDeclarationPanel`。
- 默认收起。
- 不再用“标记为 AI 生成内容”作为入口。
- 保留训练许可，并明确这是用户声明。
- 写入版权记录和报告字段时使用新的“作品声明与授权策略”字段，不再继续扩展旧 AI 标记字段。

### Phase C：版权库字段断舍离

目标：

- 版权库从“多平台输出记录”改为“保护副本与版权记录”。
- 桌面端和移动端使用同一组字段展示记录详情、报告摘要和同步 payload。
- 旧平台字段只允许在一次性迁移里读取，用于把历史记录折算为保护副本；迁移完成后不再作为产品字段、UI 字段或新代码依赖继续存在。

需要移除的产品字段：

| 旧字段 / 旧语义 | 处理方式 | 新字段 / 新语义 |
| --- | --- | --- |
| `outputDouyin` / `output_douyin` | 删除产品语义，不再展示或写入 | `protectedCopyPath` / `protected_copy_path`，仅桌面本地可用 |
| `outputBilibili` / `output_bilibili` | 删除产品语义，不再展示或写入 | 同上 |
| `outputXhs` / `output_xhs` | 删除产品语义，不再展示或写入 | 同上 |
| `outputDouyinHash` / `output_douyin_hash` | 删除平台语义 | `protectedCopyHash` / `protected_copy_hash` |
| `outputBilibiliHash` / `output_bilibili_hash` | 删除平台语义 | 同上 |
| `outputXhsHash` / `output_xhs_hash` | 删除平台语义 | 同上 |
| `输出平台` | 删除 UI 文案 | `保护副本` / `输出策略` |
| `平台优化版` | 删除 UI 文案 | `最小必要变更` |
| `isAiGenerated` / `is_ai_generated` | 删除“系统标记 AI”语义 | `workSourceDeclaration` / `work_source_declaration` |

| `humanModificationLevel` / `human_modification_level` | 重命名 | `humanEditLevelDeclaration` / `human_edit_level_declaration` |
| `customMetadata` / `custom_metadata` | 重命名 | `customRightsStatement` / `custom_rights_statement` |

新的版权库核心字段：

| 字段 | 桌面端 | 移动端 | 同步 / 报告 |
| --- | --- | --- | --- |
| `mediaKind` | 图片 / 音频 / 视频音轨 / 视频指纹存证 | 同桌面 | 同步 |

### Phase C.1：必须存储，不允许只标记或只展示

本轮字段迁移的硬要求：

```text
处理页用户填写
-> 写入正式版权库记录
-> 生成存证摘要
-> 可进入正式报告
-> 可进入云同步白名单
-> 双端详情从记录读取
```

禁止实现成：

- 只在处理页组件 state 中保存。
- 只在完成页临时展示。
- 只在报告导出时从 UI 表单拼接。
- 只在桌面端存储，移动端不存储。
- 只在移动端展示，版权库记录没有字段。

版权库记录必须新增或迁移出的持久化字段：

| 字段 | 必须落库 | 可同步 | 可进正式报告 | 说明 |
| --- | --- | --- | --- | --- |
| `protectedCopyName` / `protected_copy_name` | 是 | 是 | 是 | 保护副本文件名或移动端分享名。 |
| `protectedCopyPath` / `protected_copy_path` | 是，仅本机 | 否 | 否 | 桌面本机打开位置；移动端不得伪造路径。 |
| `protectedCopyHash` / `protected_copy_hash` | 是 | 是 | 是 | 保护副本摘要，可用于记录绑定和报告。 |
| `outputStrategy` / `output_strategy` | 是 | 是 | 是 | 默认 `minimal_required_change`。 |
| `workSourceDeclaration` / `work_source_declaration` | 是 | 是 | 是 | 用户声明：未声明 / 人工创作 / AI 辅助 / AI 生成。 |
| `trainingPermissionDeclaration` / `training_permission_declaration` | 是 | 是 | 是 | 用户声明：禁止训练 / 需单独授权 / 非商业 / 商业等。 |
| `creationMethodDeclaration` / `creation_method_declaration` | 是 | 是 | 是 | 用户声明的创作方式。 |
| `humanEditLevelDeclaration` / `human_edit_level_declaration` | 是 | 是 | 是 | 用户声明的人工编辑程度。 |
| `authenticityClaimDeclaration` / `authenticity_claim_declaration` | 是 | 是 | 是 | 用户声明的真实性口径。 |
| `customRightsStatement` / `custom_rights_statement` | 是 | 是 | 是 | 自定义版权 / 授权声明。 |

存证摘要必须包含的字段：

| 摘要字段 | 来源 | 为空时展示 |
| --- | --- | --- |
| 版权编号 | 版权库记录 `watermarkUid` | 不允许为空 |
| 版本次数 | 版权库记录 `revision` | 不允许为空 |
| 创作者身份 | 版权库记录 `creatorDisplayName` | 未记录 |
| 媒体类型 | 版权库记录 `mediaKind` | 未记录 |
| 原作品指纹 | 版权库记录 `originalHash` | 未记录 |
| 保护副本名称 | 版权库记录 `protectedCopyName` | 未记录 |
| 保护副本摘要 | 版权库记录 `protectedCopyHash` | 未记录 |
| 输出策略 | 版权库记录 `outputStrategy` | 最小必要变更 |
| 完成后验证 | 版权库记录 `writeVerificationStatus` / `writeVerificationMessage` | 未记录 |
| 第三方验证 | 版权库记录 `thirdPartyVerificationStatus` | 未记录 |
| 可信时间 | 版权库记录 `trustedTimeStatus` / `trustedTimeAt` | 未记录 |
| 作品来源声明 | 版权库记录 `workSourceDeclaration` | 未声明 |
| 训练许可声明 | 版权库记录 `trainingPermissionDeclaration` | 禁止模型训练 |
| 创作方式声明 | 版权库记录 `creationMethodDeclaration` | 未声明 |
| 人工编辑声明 | 版权库记录 `humanEditLevelDeclaration` | 未声明 |
| 真实性声明 | 版权库记录 `authenticityClaimDeclaration` | 未声明 |
| 自定义版权声明 | 版权库记录 `customRightsStatement` | 无 |

存证摘要生成规则：

- 桌面端“复制存证摘要”、移动端“复制存证摘要”、版权库详情摘要和正式报告摘要必须从已持久化的版权库记录读取。
- 写入完成页可以展示摘要，但展示内容也必须来自刚写入的记录对象，而不是表单临时值。
- App 重启后，同一条记录仍必须能复制出同样的声明字段。
- 云同步拉取到另一端后，如果同步 payload 包含声明字段，另一端版权库详情和摘要必须显示同一声明。
- `protectedCopyPath` 不得进入存证摘要、正式报告或云同步；摘要只能写保护副本名称和摘要。

字段默认值：

| 字段 | 默认值 | 原因 |
| --- | --- | --- |
| `outputStrategy` | `minimal_required_change` | 固化处理页第一性原则 |
| `workSourceDeclaration` | `unspecified` | 不替用户判断是否人工或 AI |
| `trainingPermissionDeclaration` | `prohibited` | 默认保护创作者权益，用户可改 |
| `authenticityClaimDeclaration` | `unspecified` | 不替用户做真实性鉴定 |
| `customRightsStatement` | 空 | 可选声明 |

历史数据迁移口径：

- 旧 `output_douyin / output_bilibili / output_xhs` 中第一个非空路径迁移为 `protected_copy_path`。
- 对应第一个非空 hash 迁移为 `protected_copy_hash`。
- 历史记录迁移后不再显示“来自抖音 / B站 / 小红书”，只显示“历史保护副本”。
- 旧 `is_ai_generated = true` 迁移为 `work_source_declaration = ai_generated`。
- 旧 `is_ai_generated = false` 不迁移为“人工创作”，而是迁移为 `unspecified`，避免替用户补声明。
- 旧训练许可、生成方式、人工修改和真实性字段按语义迁移到新声明字段。
- 迁移完成后，新写入路径不得再写旧平台字段或旧 AI 标记字段。

同步与隐私边界：

- `protected_copy_path` 不进入云同步 payload。
- 原始媒体路径、保护副本路径、本地 bundle 路径仍然不同步。
- `protected_copy_hash`、`protected_copy_name`、声明字段、完成后验证状态可以同步。
- 报告可以展示保护副本名称、保护副本摘要、输出策略和用户声明，但必须继续说明这不是 AI 检测或法律授权判定。

### Phase D：后端参数收口

- UI 不再传平台数组作为用户选择结果。
- 视频 L1 音轨水印使用内部单一保护副本目标，不再暴露平台 preset。
- `aspectStrategy`、`encodingMode` 从用户可见选项中移除，保留为系统内部策略或删除。
- 后端新记录写入 `protected_copy_*` 与 `output_strategy`，不得再写 `output_*` 平台字段。
- 合同测试必须阻断新代码继续引用平台输出产品语义。

## 5. 不可越界表达

禁止出现：

- “检测 AI 生成内容”
- “识别作品是否由 AI 生成”
- “自动判断训练许可”
- “平台优化版输出”
- “抖音 / B站 / 小红书版权保护专版”
- “L2 视频指纹存证可证明画面水印命中”
- “L3 视频画面盲水印已开放”

允许表达：

- “记录创作者声明”
- “训练许可声明”
- “最小必要变更”
- “保护副本”
- “完成后验证”
- “L1 视频音轨水印”
- “L2 视频指纹存证”
- “L3 当前不开放”

## 6. 当前结论

本轮已按以下取舍完成桌面端和移动端实施：

| 类型 | 功能 |
| --- | --- |
| 保留主流程 | 图片盲水印、音频盲水印、L1 视频音轨水印、L2 视频指纹存证、预检、完成后验证、入库 |
| 降级附属 | 作品来源声明、AI 辅助声明、训练许可、商业使用声明、自定义版权声明 |
| 移除主流程 | 平台画幅、平台输出、裁剪、黑边、编码模式、多平台分发 |

已实施范围：

- 桌面处理页移除抖音 / B站 / 小红书平台卡、画面策略、编码模式和多平台输出心智。
- 桌面视频写入用户可见口径收敛为 L1 视频音轨水印，内部旧 pipeline 兼容参数不再作为产品语义展示。
- `AIContentMarker` 重构为“作品声明与授权策略”，只记录用户声明，不表达 AI 检测。
- 桌面版权库、存证摘要、正式报告、云同步 payload 和验证匹配已迁移到保护副本、输出策略和声明字段。
