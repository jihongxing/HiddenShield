# HiddenShield 宣传性能专项基准 v1

更新时间：2026-07-31

## 1. 目的

本基准为宣传性能图提供用户可理解、可复现的固定素材口径：

- 图片：约 10 MiB、约 12 MP 的 JPEG。
- 音频：约 20 MiB、约 3 分钟的 FLAC。

结果只用于描述当前固定 Windows 测试设备和 Release 构建下的参考性能，不构成所有设备、素材或版本的固定 SLA。

## 2. 测试环境

| 项目 | 配置 |
| --- | --- |
| HiddenShield | `v0.1.3` 工作区 |
| 构建模式 | Rust `release` |
| CPU | AMD Ryzen 5 4500U，6 核 / 6 线程 |
| 内存 | 15.37 GiB |
| 系统 | Windows 11 Home China，10.0.26200 |
| 磁盘 | Samsung SATA SSD，约 476.9 GiB |
| FFmpeg | 8.0.1 essentials build |

每个素材先预热 1 次，再正式测量 5 次。每个素材桶包含 5 份确定性标准化素材，因此每项操作共记录 25 个正式测量值。

## 3. 素材桶

### 3.1 图片

- 格式：JPEG。
- 分辨率：4000×3000。
- 像素：12 MP。
- 文件大小：10.79–10.80 MiB。
- 数量：5 张。
- 生成方式：确定性 FFmpeg 图像滤镜；用于固定解码复杂度和重复基准，不表述为真实用户照片。

### 3.2 音频

- 格式：FLAC。
- 时长：180 秒。
- 采样率：44.1 kHz。
- 声道：双声道。
- 位深：16-bit。
- 文件大小：18.83–19.69 MiB。
- 数量：5 首。
- 生成方式：确定性音调与噪声组合；用于固定压缩复杂度和重复基准，不表述为真实歌曲。

## 4. 计时边界

### 4.1 图片写入

从原始 JPEG bytes 调用 `WatermarkService::embed` 到生成 PNG 保护副本：

- 包含 JPEG 解码。
- 包含共享核心写入。
- 包含保护副本 PNG 编码。
- 不包含原始 JPEG 的磁盘读取和桌面 UI 操作。

### 4.2 图片读取

对内存中的 PNG 保护副本调用 `WatermarkService::extract`：

- 包含共享核心读取和 UID 验证。
- 不包含保护副本磁盘读取和桌面 UI 操作。

### 4.3 音频写入

“音频写入总计”定义为：

1. FFmpeg 将原始 FLAC 解码为保持 44.1 kHz / 双声道的 16-bit WAV，并读取准备后的 WAV bytes。
2. 对准备后的 WAV bytes 调用 `WatermarkService::embed` 生成 WAV 保护副本。

不包含原始 FLAC 选择、版权库记录或桌面 UI 操作。

### 4.4 音频读取

对内存中的 WAV 保护副本调用 `WatermarkService::extract`：

- 包含共享核心读取和 UID 验证。
- 不包含保护副本磁盘读取和桌面 UI 操作。

## 5. 正式结果

| 用户可理解的素材 | 写入平均 | 写入 p95 | 读取平均 | 读取 p95 |
| --- | ---: | ---: | ---: | ---: |
| 约 10.8 MiB、12 MP JPEG | 985.73 ms | 1191.40 ms | 49.00 ms | 56.65 ms |
| 约 19.3 MiB、3 分钟 FLAC | 2284.72 ms | 2387.16 ms | 221.83 ms | 252.12 ms |

音频写入总计中的内部拆分：

| 操作 | 平均 | p95 |
| --- | ---: | ---: |
| FLAC → WAV 准备 | 134.18 ms | 172.33 ms |
| WAV 核心写入 | 2150.54 ms | 2237.52 ms |

所有 5 张图片和 5 首音频均完成写后回读，并恢复与写入一致的 UID。

## 6. 宣传图锁定数字

为避免虚假精度，宣传图采用两位有效数字：

### 图片

**约 10 MB 高清图片**

- 写入：约 0.99 秒。
- 读取：约 0.05 秒。
- 小字规格：JPEG · 12 MP · 4000×3000。

### 音频

**约 20 MB 高品质音频**

- 写入：约 2.28 秒。
- 读取：约 0.22 秒。
- 小字规格：FLAC · 约 3 分钟 · 44.1 kHz · 双声道。

宣传图底部必须持续显示：

> 固定 Windows 测试设备与 Release 构建下的标准化素材平均值；实际性能受设备、素材内容和版本影响，不构成固定 SLA。

不得使用：

- “真实用户照片平均 0.99 秒”。
- “真实歌曲平均 2.28 秒”。
- “任意 10 MB 图片或 20 MB 音频均在该时间内完成”。
- “完整桌面操作只需该时间”。

## 7. 复现方式

```powershell
npm run watermark:promo-performance-fixtures -- watermark-core/target/promo-performance-fixtures-v1

npm run watermark:promo-performance-bench -- `
  --fixture-dir watermark-core/target/promo-performance-fixtures-v1 `
  --output-dir watermark-core/target/promo-performance-benchmark-v1 `
  --iterations 5 `
  --warmups 1
```

生成内容：

- 素材 manifest：`watermark-core/target/promo-performance-fixtures-v1/manifest.json`
- 原始结果：`watermark-core/target/promo-performance-benchmark-v1/report.json`
- 阅读报告：`watermark-core/target/promo-performance-benchmark-v1/report.md`

## 8. 推荐下一步

使用本文件锁定的两组数字制作第二张宣传图；发布前由产品负责人检查图片中同时保留素材规格、测试口径和“不构成固定 SLA”提示。
