# 本地批量订阅门禁与队列设计

## 1. 目标

本地批量处理作为 Creator 订阅权益，不向 Free 提供小批量试用。

第一版目标是先固定成熟产品行为：

- Free 可以看到本地批量入口。
- Free 点击后只看到权益说明和升级路径。
- Free 不进入文件选择。
- Free 不创建本地批量队列。
- Creator 可以进入批量队列页。
- 批量任务后续复用单文件图片 / 音频写入能力。
- 每个成功文件独立入库，失败项不影响已完成项。

## 2. 权益判断

统一使用权益字段：

```json
{
  "batch_processing": true
}
```

规则：

- `batch_processing != true`：阻断在文件选择之前。
- `batch_processing == true`：允许进入批量队列。
- 本地批量不进入 quota ledger。
- 成功完成的本地批量文件可进入 usage ledger。
- 失败、取消、崩溃不入账。

## 3. 批量任务模型

建议字段：

- `updated_at`
- `status`
- `media_kind`

- `completed_items`

- `cancelled_items`
- `entitlement_plan_code`

- `output_ref`
- `vault_record_id`
- `write_verification_status`
- `write_verification_message`
- `created_at`
- `updated_at`

## 4. 状态机

### 4.1 BatchJobStatus

- `draft`：已进入页面，尚未选择文件。
- `queued`：已创建队列，等待执行。
- `running`：正在执行。
- `paused`：用户暂停。
- `completed`：全部完成。
- `completed_with_failures`：部分成功，部分失败。
- `cancelled`：用户取消。
- `failed`：任务级失败。

### 4.2 BatchItemStatus

- `queued`
- `running`
- `verified`
- `failed`
- `cancelled`

## 5. 执行策略

图片：

- 逐个调用现有图片写入管线。
- 完成后立即做写后验证。
- 验证通过后写入版权库。

音频：

- 只接受 30 秒以上音频。
- 逐个调用现有音频写入管线。
- 完成后立即做写后验证。
- 验证通过后写入版权库。

失败处理：

- 单项失败只标记该项失败。
- 已完成项保留版权库记录。
- 支持单项重试和全部失败项重试。

## 6. 两端交互

桌面端：

- 侧边栏提供“本地批量”一级入口。
- Free 展示订阅门禁说明。
- Creator 展示队列页和队列规则。

移动端：

- 工作台提供“本地批量”入口。
- Free 展示订阅门禁说明。
- Creator 展示队列页和队列规则。

## 8. 当前实现说明

当前桌面端和移动端都已经可以在 Creator 权益下创建本地批量队列。

现阶段队列负责产品状态、本地持久化和本地真实执行：

- 桌面端和移动端都应选择图片和常见音频文件。
- 移动端音频写入 / 解析由本地桥接先归一化为 WAV，再复用 `watermark-core`。
- 不支持的扩展名进入 `failed`。
- 队列可暂停、继续、取消。
- 失败项可重新放回 `queued`。
- 图片 / 音频项可顺序执行现有单文件写入管线，完成后立即验证并写入版权库。
- 图片 / 音频项状态会在 `queued / running / verified / failed / cancelled` 间流转。
- 桌面端写入 `vault.db` 的 `local_batch_jobs` 和 `local_batch_items`。
- 移动端写入 `hidden_shield_mobile.db` 的 `local_batch_jobs` 和 `local_batch_items`。
- 桌面端批量项复用单文件 Tauri 管线，因此成功项已由底层 `usage_ledger` 写入 `watermark_image` / `watermark_audio`。
- 移动端批量项在写后验证通过后写入本地 `usage_ledger`，设置页显示累计完成、图片 / 音频分布和最近完成记录。
- 本地批量 usage ledger 只用于观测和商业分析，不进入 quota ledger，不扣减本地批量次数。

这样做的原因是：批量执行必须复用现有单文件写入和完成后验证能力，不能单独开一条绕过验证的路径。

当前风险：

- 桌面端图片批量复用现有 Tauri 管线，启动失败和运行失败会进入失败项；取消当前项依赖现有管线取消能力。
- 移动端图片批量会读取本机文件路径，Web 预览环境不能执行真实本地文件批量。
- 音频批量复用单文件音频写入和写入后验证能力；短于 30 秒的音频会按单文件规则失败并保留在队列中。
