# HiddenShield 双端能力一致性 QA 清单

本文档用于桌面端 Tauri 与移动端 Flutter 的人工回归。自动化门禁以 `npm run dual:contract` 为准，人工 QA 用于确认真实交互体验没有偏离同一套产品口径。

## 1. 基础原则

- 桌面端和移动端使用同一套核心术语：图片写入、音频写入、验证、版权库、正式报告、云同步、视频指纹存证。
- 产品界面不展示“桥接层”“临时直连”“调试配对码”等技术性同步语言。
- 默认不上传原始媒体、加水印媒体或本地路径。
- 正式报告不是法律意见或司法鉴定，只作为技术验证辅助材料。

## 2. 图片写入与验证

- 双端均可进入图片写入页，并看到 JPG / PNG / BMP / TIFF / WebP 支持说明。
- 写入完成后双端均展示保护副本、版权编号、写入次数、验证状态和版权库入口。
- 作为新版写入时，双端均展示父水印、写入次数和重写说明。
- 图片验证页双端均能区分可信命中、疑似命中、未登记水印和提取失败。
- 双端对 JPEG 压缩、轻度缩放 / 轻裁剪、局部遮挡、90 / 180 / 270 度旋转与水平 / 垂直镜像不做冲突承诺。

## 3. 音频写入与验证

- 双端均说明只保护 30 秒以上完整音频作品。
- 短于 30 秒时，双端均提示“音频时长不足 30 秒，未生成保护副本”，并不创建版权库成功记录。
- 无法确认时长时，双端均提示“无法确认音频时长，未生成保护副本”，并不创建版权库成功记录。
- 双端处理音频时不得把双声道静默改成单声道，也不得把采样率变化包装成无损保留。
- 音频验证页双端均能显示水印提取结果、本机版权库匹配状态、置信度和失败原因。

## 4. 版权库与报告

- 同一条图片 / 音频版权记录在双端展示标题、类型、版权编号、写入次数、原始哈希、父水印和验证状态。
- L2 视频存证记录在双端展示存证编号、指纹根、指纹包摘要和采样策略。
- 正式报告入口双端一致，不包含原始媒体、加水印媒体、本地路径或本地 bundle 路径。
- 报告页或报告草稿必须保留“报告不是法律意见或司法鉴定”的边界说明。

## 5. 云同步一致性

- 云同步只同步账户、工作区、设备、创作者身份、订阅权益、版权记录元数据、验证记录、审计记录和同步状态摘要。
- 同步 payload 不包含 `input_ref`、`output_ref`、`local_path`、`output_douyin`、`output_bilibili`、`output_xhs` 或 `bundle_path`。
- 同 UID 同 hash 时保留最高写入次数。
- 同 UID 不同 hash 时保留记录并标记为待登记仲裁，不静默覆盖本机记录。
- 失败重试保持自动退避和手动重试入口，达到重试上限后用户可理解下一步动作。
- 退出账户后只清云身份、令牌、工作区、创作者档案和权益；本地版权库与本地队列继续保留。

## 6. L2 视频存证

- 桌面端保留生成和提交 L2 指纹包能力。
- 移动端只查看同步来的 L2 存证记录，不提供本地视频盲水印写入入口。
- 双端均明确 L2 是视频指纹存证，不是视频画面盲水印。
- 双端均说明不会上传原始视频、加水印视频、本地视频路径或本地 bundle 路径。

## 7. 自动化门禁

- `npm run dual:contract`
- `npm run build`
- `flutter analyze`
- `flutter test`
- `cargo test --manifest-path src-tauri/Cargo.toml --lib -- --skip l3`
- `cargo test --manifest-path feedback-backend/Cargo.toml --lib`

任一检查失败时，不应继续把双端一致性相关改动合入主分支。
