# 双端现有能力发布计划

状态：发布主线，L3 冻结为内部储备。

本文用于把 HiddenShield 从“持续研发 L3”切换到“接入现有可承诺能力并发布版本”。短期不继续推进 L3 视频画面盲水印算法、完整 24 样本池长跑、云端任务包装或 `video_minutes` 扣费；L3 已有证据只保留为内部研发资产和未来高阶产品线储备。

封版执行总表见 `docs/封版收口计划.md`。后续默认只做阻断修复、回归验收、运行态 QA、文案边界收口和发布材料，不再新增大功能。

## 1. 发布原则

- 发布版只承诺 `docs/当前真实能力边界说明.md` 中“可对用户承诺”的能力。
- L3 视频画面盲水印继续属于“只能内部测试”，不得进入 UI、订阅权益、销售材料、正式报告、云任务或账本扣费。
- 桌面端、移动端、后端必须共享 Free / Creator / Studio / Enterprise 术语。
- 图片、音频、L1 视频音轨水印必须继续由 `watermark-core` 提供正式写入、读取、payload、版权编号、重写检测和写入后验证能力。
- L2 视频指纹存证只作为不可逆画面指纹存证和相似性证据增强，不能包装成视频画面盲水印。
- 云同步、报告、匿名反馈、诊断日志和商业指标不得上传原始媒体、加水印媒体、本地路径或保护副本路径。
- Web 预览只用于 UI 体验，不作为正式移动端能力；preview 结果不得进入版权库、云同步、正式报告或跨端 QA 证据，也不得展示成正式 `HS-...` 版权编号。

## 3. 发布前必须完成

自动化门禁：

- `npm run build`
- `cargo test --manifest-path src-tauri/Cargo.toml --lib -- --skip l3`
- `cargo test --manifest-path feedback-backend/Cargo.toml --lib`
- `flutter analyze`（在 `mobile_app` 目录）
- `flutter test`（在 `mobile_app` 目录）
- `npm run dual:contract`
- `npm run commercial:contract`
- `npm run commercial:ci`
- `npm run watermark:architecture-contract`
- `npm run watermark:cross-end-release`
- `npm run watermark:video-phase-contract`

运行态验收：

- 桌面端完成图片写入、音频写入、验证、版权库、正式报告、云同步、本地批量、L2 视频指纹存证。
- 原生移动端完成图片写入、音频写入、验证、保护副本分享、版权库、复制存证摘要、正式报告草稿、云同步、本地批量、设置页反馈和日志。
- 用桌面端写入的图片 / 音频在原生移动端验证；用原生移动端写入的图片 / 音频在桌面端验证。
- 用移动端分享出的图片 / 音频保护副本在桌面端读取 / 验证 / 解密；用桌面端导出的图片 / 音频保护副本在原生移动端读取 / 验证 / 解密。
- Free / Creator / Studio / Enterprise 权益门禁双端一致。
- 关闭后端时，双端只展示产品化错误，不暴露技术异常。
- L2 视频指纹存证在桌面端生成和提交后，移动端通过同步只读查看，不暴露本地路径。

外部阻断：

- Free 单份报告真实付款上线需要真实微信商户材料、HTTPS 回调域名、沙箱或生产订单、退款 / 撤销验收；未配置时展示支付通道未完成配置。
- 法务上线仍需要隐私政策、用户协议、支付与订阅条款完成正式审阅。

## 4. L3 冻结策略

短期不继续执行：

- `HIDDENSHIELD_L3_FULL_RELEASE_POOL=1` 完整 24 样本池长跑。
- L3 桌面端或移动端 UI 接入。
- L3 云端任务、策略包下发、账本扣费或 `video_minutes` 消耗。
- L3 销售话术、订阅权益或正式报告字段。
- 4K / 8K L3 产品线设计。

保留：

- `watermark-core` 中已完成的 staged API、测试和文档。
- L3 边界合同，防止 staged 能力被误包装成可售能力。
- 未来当真实付费需求明确时，再从 `docs/当前真实能力边界说明.md`、`docs/Phase I-6 L3 2K高码率release样本池与阈值策略.md` 和商业化 Roadmap 重新评估。
- 发布封版前继续运行 `watermark:architecture-contract`，确认后端没有新增核心外盲水印算法，Web preview 没有进入 vault / sync / report，也没有正式版权编号暗示。
