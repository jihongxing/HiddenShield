# Project Agent Instructions

The canonical project agent instructions live in [AGENTS.md](./AGENTS.md).

This file exists as a lowercase compatibility pointer for tools or agents that look for `agent.md`.

## Core Hard Constraint

Every completed task must end with a concrete recommended next step.

The recommendation must be specific, actionable, and tied to the current project state. Do not end a task response with a generic optional offer.

## Commercialization Roadmap Constraint

Commercialization work must follow [docs/商业化落地Roadmap.md](./docs/商业化落地Roadmap.md).

For any task that touches subscription, entitlement, batch processing, cloud sync monetization, cloud video processing, team workspace, payment, pricing, or commercial UI, check the roadmap first and update it after completion.

## Desktop/Mobile Consistency Roadmap Constraint

Desktop/mobile consistency work must follow [docs/双端能力一致性Roadmap.md](./docs/双端能力一致性Roadmap.md).

For any task that touches desktop/mobile parity, image or audio capability alignment, vault fields, verification wording, report fields, sync behavior, L2 video notary display, mobile/desktop UX wording, or cross-platform QA, check the roadmap first and update it after completion.
