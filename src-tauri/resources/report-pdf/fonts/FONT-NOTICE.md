# Font Notice

The controlled report fonts are static instances derived from Noto Sans SC and Noto Serif SC.

The embedded font name tables identify the license as the SIL Open Font License, Version 1.1. The files retain their original license metadata and are bundled only for deterministic HiddenShield PDF rendering.

- `NotoSansSC-Controlled.ttf`: static weight 400 instance.
- `NotoSerifSC-Controlled.ttf`: static weight 700 instance.
